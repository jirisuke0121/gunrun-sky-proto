# 空中回廊 追跡（GunRun 試作）

一人称パルクールで、2分間ゾンビの群れから逃げ切る試作です。先行プレイ・感想募集中。

**遊ぶ：** https://jirisuke0121.github.io/gunrun-sky-proto/ （iPhone は横向き、PC はブラウザで）

## 操作
- PC：WASD 移動 / Space ジャンプ / C スライド / Q フック / G 煙幕 / クリックか F でナイフ / Esc 一時停止
- 武器：タイトル画面か設定で選べます。HG（精密・遠くまで）/ SG（近距離・扇状に押し流す）/ SMG（連射・足止め）/ MG（60発装填・長いリロード）。どれも走る・跳ぶ・スライド中に撃てて、動きながら撃つと押し返しが1.25倍になります
- 銃（PC）：E 長押しで撃つ / R 装填。最寄りのゾンビに自動で照準が付き（赤い輪）、カメラは動きません。弾数は武器ごとに異なり、HGは装填12＋予備36発です。設定でオートエイムや予備弾を変えられます（オートエイムを切って頭に当てると一撃）
- 煙幕：最初は1個。技（スライド・壁走り・縁つかみ・はしご・ジップライン・フック）を3回決めるごとに+1個、最大2個。投げた場所に7秒間の煙が広がり、煙越しのゾンビはプレイヤーを追跡・攻撃できません
- スマホ：左の円で移動、右でジャンプ・スライド。フックは画面の輪をタップ。ナイフは自動、銃は「撃つ」「装填」ボタン、煙幕は「煙幕」ボタン

## 2026-10-24 射撃の手応え（dev版のみ）
- 銃声（実録＋低音の合成）：「The Free Firearm Sound Library」（CC0・クレジット不要。Ben Jaszczak ほか）から、HG=Walther PPQ、SG=Winchester Model 12、SMG=Carl Gustav M45、MG=AK-47 の単発を各2テイク切り出し（`dev/assets/sfx/`、モノラル32kHz・合計0.1MB）。全テイクに発射後0.07〜0.16秒で射撃場の壁の反響や薬莢の音が入っており、圧縮で持ち上がると「別の音が混じる」ため、反響の手前（HG約150ms・SG約130ms・SMG/MG約75ms）で切った乾いた音だけを使う。これに、①低音の持ち上げ・歪み・コンプ、②音程が落ちる低音の「ドン」（HG 230→85Hz など）、③合成の残響を重ね、リミッターで割れを防ぐ。薬莢の金属音（鈴のような音）は廃止。毎発テイクを替え、ピッチ±4%・音量を揺らす。読み込めない間・失敗時は下の合成音に切り替わる
- 銃声（合成・予備）：作り直し。ゲーム共有のノイズは約115Hz以下しか出ない低音だけの音で、高音の破裂成分が鳴っていなかった。専用の白色ノイズで「瞬間の破裂→フィルタが高→低に落ちる本体→低音ドン」の3層に、歪み・コンプ・短い残響・こだまを足した。毎発ピッチ±8%・音量±10%で変化（測定：最初の60ms内の2kHz以上のエネルギーが HG 4%→19%、SMG 5%→33%）
- 命中：体は鈍い「ドスッ」＋血5粒、ヘッドショットは高い「キン」＋赤い血14粒、撃破は血18〜26粒（頭は赤が濃い）。手動ヘッドショットの撃破だけ0.05秒のヒットストップ（オートエイム中の頭は対象外）
- 曳光：細い線をやめ、橙色の太い光弾が飛ぶ（明るい砂色の背景で消えていた加算合成をやめ、距離に応じて太さを保つ）。SGは散弾4本
- 薬莢（SGは赤）は走行速度を引き継いで見える時間を延長。銃口の煙、フラッシュは不透明の黄色（0.06秒）
- 血・命中の閃光は距離に応じて大きさを保つ（15m先でも約10px）。被弾したゾンビは0.1秒赤く光り、撃破では命中マークが大きくなる
- 画面揺れ：SG 0.55・MG 0.3（動きの少ない設定では出ない）
- 未対応：連射で視点が戻らない件、銃モデルと弾道のずれ（別途）

## 2026-10-23 iPhoneでページが拡大される不具合の対策（dev版）
- 原因：iPhoneのSafariは `user-scalable=no` を無視する。左親指（移動）と右親指（視点）が近づく・離れる動きが「ピンチ拡大」と判定され、拡大したまま戻らなかった。素早い2回タップも拡大になる。
- 対策：ピンチ（gesture系イベント・2本指のtouchmove）とダブルタップを止める。それでも拡大した場合は、拡大率を検知して自動で元に戻す（元に戻す処理は実機未確認）。
- 反映先：`dev/`（ビルド名 2026-10-23b-dev）。公開版への反映は未実施。

## 2026-10-23 ゾンビにつかまれたときの急加速を廃止（dev版）
- 原因：つかまれたとき、ゾンビと反対向きに +4 m/s（追跡者は +7）を今の速度へ足していた。走り9.2 m/s のときは 13.2 m/s まで跳ね上がり、1秒たっても約12 m/s のまま。速度線と視野の広がりも重なって「突然加速」に感じた。
- 対策：つかまれても、走りの速さ（9.2 m/s）か、つかまれる前の速さのうち大きいほうを超えないようにした（押しのける向きは残す）。
- 計測（headless、走行中に背後からつかまれた直後）：変更前 最大13.2 m/s → 変更後 9.2 m/s。
- 反映先：`dev/`（ビルド名 2026-10-23c-dev）。公開版は未反映。
