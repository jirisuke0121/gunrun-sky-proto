## 2026-11-01：空と霧を青系に・地区ごとの色づけ（黒く描画される不具合の原因と修正）

- 空の上下グラデーションと霧を、砂色から青みのある霞（霧 `#bcd2e4`、空の天頂 `#6f9fd6`）に変更し、マップの色も地区ごと（西=レンガ、東=青緑、北=苔、南=薄い赤）に滑らかに変える（`look-pass.js`）。近くの砂色の壁・屋根と遠くの柱・塔が色で分かれ、今いる地区が色で分かる。色だけの変更で、メッシュ・光源・テクスチャは増えず、draw call は変更前後で同じ（565）。シェーダーのプログラム数は20→22（頂点カラー用の2種）。比較用：`?look=classic`（従来の砂色）、`?look=sky`（空と霧のみ）。
- 黒く描画される不具合の原因：three.js は、ジオメトリの属性（位置・法線・色など）のGPUバッファを、ジオメトリごとに「1フレームに1回」の更新処理で作る。この更新は同じフレーム番号なら飛ばされる作りで、このゲームは影の更新を1フレームおきにしている（`enhancements.js` の `shadowMap.needsUpdate` の切り替え）ため、影の更新が無いフレームでは、メインの描画で更新が飛ばされることがある。すでに描画した後のジオメトリに、そのフレームで `color` 属性を足すと、色のGPUバッファが無いまま頂点配列の状態（VAO）が作られ、「最新」として保存される。以後バッファができても作り直されず、シェーダーは色を既定値（0,0,0）で読むので、その面は黒のまま描画される。頂点カラーを使う描画経路（`vertexColors`）の面だけが黒くなり、読み込みの度に起きたり起きなかったりしたのはこのタイミングのため。
- 確認：色の属性を足す瞬間を、影の更新が飛ばされるフレームに合わせて意図的に作ると、既存のジオメトリに足した場合は必ず黒くなり（面の12%）、新しいジオメトリに差し替えた場合は黒くならない（0.1%）。差し替え前は、ゲーム開始後に地区へ移動する検証で4回中1回黒くなり、`geometry.dispose()` で作り直す対処は14回中0回、最終の修正（新しいジオメトリを渡す）は10回中0回だった。修正は、色を足す代わりに、複製したジオメトリに色を足して差し替える（`look-pass.js`）。
- 確認：単体テスト一式は全て終了コード0。

- PC：WASD 移動 / Space ジャンプ / C スライド / Q フック / 1 閃光弾（G も可）/ 2 分身 / クリックか F でナイフ / Esc 一時停止
- 武器：HGで開始。SG（近距離・扇状に押し流す）/ SMG（連射・足止め）/ MG（60発装填・長いリロード）は、10秒ごとに屋根・上層へ落下する武器箱で取得します。触れると自動装備・弾薬補充。同時に最大5個、未取得の箱は50秒で消えます。どれも走る・跳ぶ・スライド中に撃てて、動きながら撃つと押し返しが1.25倍になります
- 銃（PC）：近い敵を自動で狙って撃ち、弾切れ時に自動装填。Xで自動射撃を停止／再開。最寄りのゾンビに自動で照準が付き（赤い輪）、カメラは動きません。弾数は武器ごとに異なり、HGは装填12＋予備36発です。設定でオートエイムや予備弾を変えられます（オートエイムを切って頭に当てると一撃）
- 閃光弾：最初は1個。技（スライド・壁走り・縁つかみ・はしご・ジップライン・フック）を3回決めるごとに+1個、最大2個。Gキー／「閃光弾」で正面に投げ、周囲8mのゾンビの移動・攻撃を4秒停止。壁越しには効きません
- スマホ：左の円で移動、右でジャンプ。低い通路へ走ると自動でスライドしてくぐります。フックは画面の輪をタップ。ナイフ・照準・射撃・装填は自動。銃は「自動射撃を停止／再開」で弾を温存し、閃光弾は「閃光弾」ボタン

## 2026-10-24 射撃の手応え（dev版のみ）
- 銃声（元の録音に忠実）：「The Free Firearm Sound Library」（CC0・クレジット不要。Ben Jaszczak ほか）の録音を、**加工せずそのまま**使う（`dev/assets/sfx/`、ステレオ44.1kHz。96kHzから変換しても聞き分けられないことをユーザーが確認済み）。HG=Springfield 1917 の B_16P（2発）、SG=Winchester Model 12 の K_22P・K_17P（4発）、MG=AK-47 の C_28P（4発）は、元の余韻と反響を含めて1.2秒を使う。SMG=Carl Gustav M45 の G_35P は連射の1発ずつ（約93ms、9本）に、連射の最後の1発（余韻つき、2本）を加える。MGの連射用には C_27P の連射から約90msの1発を6本。直前の発射から0.2秒未満なら短い1発、それ以外は余韻つきの長い1発を選ぶ（連射で余韻が積み重ならないように）。加工は、音の頭のプツッを防ぐ1.5msのフェードイン、末尾のフェードアウト、音量合わせ、保険のリミッターだけ。左右の幅・低音・圧縮・残響は触らない。元のファイルと並べて聞いて「元（無加工）が良い」とユーザーが選んだため。URLに `?snd=body` を付けると低音の持ち上げ＋1オクターブ下の層を足した版、`?snd=full` で以前の濃い加工版、`?snd_debug=1` で鳴った武器とテイク名を画面左下に表示。読み込めない間・失敗時は下の合成音に切り替わる
- 銃声（合成・予備）：作り直し。ゲーム共有のノイズは約115Hz以下しか出ない低音だけの音で、高音の破裂成分が鳴っていなかった。専用の白色ノイズで「瞬間の破裂→フィルタが高→低に落ちる本体→低音ドン」の3層に、歪み・コンプ・短い残響・こだまを足した。毎発ピッチ±8%・音量±10%で変化（測定：最初の60ms内の2kHz以上のエネルギーが HG 4%→19%、SMG 5%→33%）
- 命中：体は鈍い「ドスッ」＋血5粒、ヘッドショットは低い「ゴッ」を上乗せ（高い「キン」は廃止）＋赤い血14粒、撃破は血18〜26粒（頭は赤が濃い）。手動ヘッドショットの撃破だけ0.05秒のヒットストップ（オートエイム中の頭は対象外）
- 曳光：細い線をやめ、橙色の太い光弾が飛ぶ（明るい砂色の背景で消えていた加算合成をやめ、距離に応じて太さを保つ）。SGは散弾4本
- 薬莢（SGは赤）は走行速度を引き継いで見える時間を延長。銃口の煙、フラッシュは不透明の黄色（0.06秒）
- 血・命中の閃光は距離に応じて大きさを保つ（15m先でも約10px）。被弾したゾンビは0.1秒赤く光り、撃破では命中マークが大きくなる
- 画面揺れ：SG 0.55・MG 0.3（動きの少ない設定では出ない）
- 未対応：連射で視点が戻らない件、銃モデルと弾道のずれ（別途）

## 2026-10-30：自動射撃を基本操作にする
