# 空中回廊 追跡（GunRun 試作）

一人称パルクールで、2分間ゾンビの群れから逃げ切る試作です。先行プレイ・感想募集中。

**遊ぶ：** https://jirisuke0121.github.io/gunrun-sky-proto/ （iPhone は横向き、PC はブラウザで）

## 操作
- PC：WASD 移動 / Space ジャンプ / C スライド / Q フック / クリックか F でナイフ / Esc 一時停止
- 武器：タイトル画面か設定で選べます。HG（精密・遠くまで）/ SG（近距離・扇状に押し流す。倒れる数が多い）/ SMG（連射・足止め。弾の消費が速い）。どれも走る・跳ぶ・スライド中に撃てて、動きながら撃つと押し返しが1.25倍になります
- 銃（PC）：E 長押しで撃つ / R 装填。最寄りのゾンビに自動で照準が付き（赤い輪）、カメラは動きません。弾は装填12＋予備36発。設定でオートエイムや予備弾を変えられます（オートエイムを切って頭に当てると一撃）
- スマホ：左の円で移動、右でジャンプ・スライド。フックは画面の輪をタップ。ナイフは自動、銃は「撃つ」「装填」ボタン
