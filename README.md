# 空中回廊 追跡（GunRun 試作）

一人称パルクールで、2分間ゾンビの群れから逃げ切る試作です。先行プレイ・感想募集中。

**遊ぶ：** https://jirisuke0121.github.io/gunrun-sky-proto/ （iPhone は横向き、PC はブラウザで）

## 操作
- PC：WASD 移動 / Space ジャンプ / C スライド / Q フック / G 煙幕 / クリックか F でナイフ / Esc 一時停止
- 武器：タイトル画面か設定で選べます。HG（精密・遠くまで）/ SG（近距離・扇状に押し流す）/ SMG（連射・足止め）/ MG（60発装填・長いリロード）。どれも走る・跳ぶ・スライド中に撃てて、動きながら撃つと押し返しが1.25倍になります
- 銃（PC）：E 長押しで撃つ / R 装填。最寄りのゾンビに自動で照準が付き（赤い輪）、カメラは動きません。弾数は武器ごとに異なり、HGは装填12＋予備36発です。設定でオートエイムや予備弾を変えられます（オートエイムを切って頭に当てると一撃）
- 煙幕：最初は1個。技（スライド・壁走り・縁つかみ・はしご・ジップライン・フック）を3回決めるごとに+1個、最大2個。投げた場所に7秒間の煙が広がり、煙越しのゾンビはプレイヤーを追跡・攻撃できません
- スマホ：左の円で移動、右でジャンプ・スライド。フックは画面の輪をタップ。ナイフは自動、銃は「撃つ」「装填」ボタン、煙幕は「煙幕」ボタン

## 2026-10-23 STEP4 切り返しのループ → 不採用（計測で差が縮んだため戻した）
柱付きの台座（高さ1m・柱4.5m）を南の路地・東の広場・中央への通りに3か所。160回ずつの比較で、上手い人82→82秒、雑な人56→61秒、地面だけ20→18秒。伸びたのは雑な人だけ。
ただしボットのゾンビは毎回最短の道を選び直すため、フェイント（切り返しでゾンビの反応の遅れを突く）の効果は測れていない。人が遊んで確かめる候補として残す。

## 2026-10-23 STEP3 建物の中を縦に抜ける（西の広場の見張り小屋）

- 北の家H2を2階建てにする案は、屋根が5mになり地面から蹴り上がれなくなって悪化したため不採用

## 2026-10-23 旧市街を広げて「屋根の上を一周」できる町に
- 西側を20m広げ（x -70まで）、家を17軒に。屋根を跳び継いで一周できます：北の列（3→4.2→5m、東へ上る）→ 低い家 → 梁 → 4.2mの家 → 板 → 6.4mの家 → 塔 → 中央の屋上 → ジップラインで下りる → 南の列（2.8→4→5→5.6→4.4→5.5→6.5m、西へ）→ 西の角 → 北の列へ戻る
- 地面から屋根へ上がる入口：木箱、階段、傾斜屋根、日よけ布、壁の蹴り上がり。真ん中の家から北と南の列へ梁と板
- 新しい動き：少し高い壁（つかめる高さ＋1.6mまで）に走り込んで跳ぶと、壁を蹴って駆け上がる（空中で1回）。日よけ布に上から落ちると大きく跳ねる（足元が約2.7m上がる）

- スピード感：大きく着地すると砂ぼこりと沈み込み、全力で走ると足元に砂ぼこり、走る速さを超える速度（スライド・壁走り・ジップライン）では画面の端に速度線

## 素材
- 新しいゾンビ4体のモデルとアニメーション：Meshyで制作。モバイル向けに軽量化（4体で約3.1MB）。詳細は [MESHY_ZOMBIES.md](MESHY_ZOMBIES.md)
- 読み込み失敗時の予備モデルとアニメーション：Quaternius「Universal Animation Library 2」（CC0）を軽量化して使用
- 設定の「ゾンビの見た目」を0にすると、旧来の手作りゾンビに戻せます
- SMGとナイフ：Meshyで生成したモデルをそれぞれ約8千三角面・512pxテクスチャへ軽量化し、`assets/smg-meshy-low.glb` と `assets/knife-meshy-low.glb` に配置。読み込めないときは軽量な組み立てモデルに切り替わります
- はしご：Meshyのモデルを約4千三角面・512pxに軽量化し、`assets/ladder-meshy-low.glb` に配置。既存のはしご形状と登攀判定を残し、装飾として重ねます
- HG・SG・MG、フック射出器・固定アンカー・ジップライン滑車・煙幕弾はMeshy原本をモバイル向けに軽量化したGLBを`assets/`に配置しています。読み込めない場合は`enhancements.js`の軽量形状へ切り替わります
- 一人称の腕の袖は、Meshyの銃や手袋になじむ暗い布の色にしています。黒い袋の飾りは暗いオリーブ色にしました
- 手袋はMeshy候補の手の甲と手首を既存の手アニメーションに合わせて加工し、`assets/glove-meshy-fitted.glb`から両手へ装着します。指と親指は既存の可動パーツを使い、GLBを読めないときは軽量形状へ戻ります。ジップライン端末・障害物の追加ディテール、煙幕の粒子と敵の視線遮蔽は`enhancements.js`にあります
- 予備弾を絞りました：SMG 30+60、MG 60+60（HG 12+36、SG 6+18は据え置き）
- BGM：低い唸りと鼓動のような合成音をプレイ中だけ小さく流します（音声ファイルなし・容量増なし）。効果音は合成音のまま
- ナイフ：振るときに白い斬撃の線が出て、刃を斜め上に構えて明るく見せます。ゾンビがナイフの届く範囲に入ると「ナイフ範囲：F / 右クリック」と表示します（PCのみ。スマホは自動で振ります）
- ゴースト：自己ベストの走りを青い人影で表示します（Hで表示・非表示）。位置は0.1秒ごとに記録し、この端末のブラウザにだけ保存します。ミッション練習では出ません
