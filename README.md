# 空中回廊 追跡（GunRun 試作）

一人称パルクールで、2分間ゾンビの群れから逃げ切る試作です。先行プレイ・感想募集中。

**遊ぶ：** https://jirisuke0121.github.io/gunrun-sky-proto/ （iPhone は横向き、PC はブラウザで）

## 現在の公開版（2026-10-25）
- タイトル画面で13種類の武器を選べます。従来のHG・SG・SMG・MGに加え、Unity Easy Weapons の Pistol・Shotgun・M4・Rail Gun・Beam Gun・Cluster Launcher・Rocket Launcher・M79 を搭載しています。
- 選んだ武器の手元モデル、弾数、連射速度、装填、銃声がプレイ中に切り替わります。Unity武器の反動・装填時の下げ動作・銃口フラッシュに加え、Pistolのスライド後退・弾切れでの停止・装填時の復帰をブラウザ側で動かします（GLBにはアニメーションクリップがありません）。Pistolの可動部品は `tools/split-easy-pistol-slide.py` で元の変換GLBから分離しています。Cluster・Rocket・M79 は着弾地点で範囲ダメージを与え、衝撃波・火球・煙・火花とUnity由来の爆発音を再生します。爆発音は爆発武器を選んだときだけ読み込みます。
- 一人称の13武器は、銃の長さ・構え位置・握る位置・反動を個別に設定しています。Unity武器の銃口の向きを補正し、装填中も銃本体を画面内へ残します。Beamと発射体の見た目は表示上の銃口から始まり、命中判定は従来どおり照準へ向かいます。ナイフや両手を使うパルクール中は、その動作用の手元に切り替わります。
- 一人称の握り手は同じUnity人間モデルから切り出した約127 KBの `assets/human-first-person-hands.glb` を使用します。出力手順は `tools/export-unity-first-person-hands.py`、武器ごとの構え設定は `first-person-weapons.js` です。
- プレイの入口はリポジトリ直下の `index.html` と `canyon.html`。`dev/` は廃止済みです。

## ジャンプガンとメニュー（2026-10-25）
- ホームの「Jump Gun（お試し）」を選び、近い床へ発砲すると反動で跳びます。真下では約3 m（標準重力・頭上の障害物なし）、後方の床を撃つと前方へ跳び出します。床の上面への命中が必要で、壁や空撃ちでは跳びません。自傷はなく、1回の飛行につき1回まで。着地すると再使用可能になり、HUDにREADY／着地待ちを表示します。一人称・Unity人間の三人称に対応します。実装は `jump-gun.js`、形状は既存の基本図形から作り、追加のモデルやテクスチャはダウンロードしません。
- 画面の「☰ メニュー」からプレイ前にもプレイ中にも調整バーを開けます。開始前は調整後にホームへ、プレイ中は一時停止してゲームへ戻ります。スマホの縦・横・自動回転表示に対応し、調整欄をスクロールできます。`game-menu.js` が共通の調整パネルを管理します。

## 旧市街のフック配置エディター
- `hook-editor.html` は旧市街の当たり判定から俯瞰立体図を作り、クリック・ドラッグ・数値入力でフックの座標を編集します。青い試射地点を指定すると射程と障害物を確認できます。
- 「このブラウザに保存」で旧市街のゲームに反映されます。保存先はブラウザのローカルストレージなので、他のプレイヤーや公開標準配置は変わりません。JSONの書き出し・読み込みで配置を受け渡せます。

## Unityキャラクター統合版（2026-10-25）
- 旧市街と岩壁渓谷のホーム画面で、従来のゾンビ4種／Unity標準／Unity進化／混合6種、従来の一人称／Unity人間の三人称を選べます。Unity人間は前進・後退・左右移動、ジャンプ、スライディング、梯子登攀、射撃・装填のアニメーションを使用し、プレイ中の `V` キーで一人称と三人称を切り替えます。スライディングはUnity素材の低姿勢移動を元に骨格を調整し、片膝をついて脚を伸ばす滑走姿勢を作っています。専用クリップのない梯子も同じ人間モデルの骨格に登攀ポーズを作って適用します。銃は選択した13種を三人称モデルにも表示します（梯子中は非表示）。
- Unity人間のアニメーション（gzip約3.3 MB）とUnityゾンビ（合計約1.1 MB）は選択時に読み込みます。ヘッドショット音（約10 KB）はプレイ開始時に読み込みます。ゾンビ声は権利確認まで含めていません。モデルの読み込みに失敗した場合は従来表示に戻ります。
- Unity標準・進化ゾンビにも遠距離用の形状を用意しました。10 m超で4,204→2,000三角形へ切り替え、9 m以内で元に戻ります。形状が同じ2種で `assets/zombie-gunrun-lo.glb`（約108 KB）を共有し、テクスチャ・骨・アニメーションは読み込み済みのものを使用します。軽量形状の読み込みに失敗した場合は元モデルを表示します。再生成は `tools/export-unity-zombie-lod.py` を使用します。
- Unity Asset Store 由来の変換モデルと効果音を含みます。ゾンビ声は別途権利条件の確認まで公開しません。

## 操作
- PC：WASD 移動 / Space ジャンプ / C スライド / Q フック / G 煙幕 / クリックか F でナイフ / Esc 一時停止
- 武器：タイトル画面か設定で選べます。HG（精密・遠くまで）/ SG（近距離・扇状に押し流す）/ SMG（連射・足止め）/ MG（60発装填・長いリロード）。どれも走る・跳ぶ・スライド中に撃てて、動きながら撃つと押し返しが1.25倍になります
- 銃（PC）：E 長押しで撃つ / R 装填。最寄りのゾンビに自動で照準が付き（赤い輪）、カメラは動きません。弾数は武器ごとに異なり、HGは装填12＋予備36発です。設定でオートエイムや予備弾を変えられます（オートエイムを切って頭に当てると一撃）
- 煙幕：最初は1個。技（スライド・壁走り・縁つかみ・はしご・ジップライン・フック）を3回決めるごとに+1個、最大2個。投げた場所に7秒間の煙が広がり、煙越しのゾンビはプレイヤーを追跡・攻撃できません
- スマホ：左の円で移動、右でジャンプ・スライド。フックは画面の輪をタップ。ナイフは自動、銃は「撃つ」「装填」ボタン、煙幕は「煙幕」ボタン

## 2026-10-24 射撃の手応え（dev版のみ）
- 銃声（元の録音に忠実）：「The Free Firearm Sound Library」（CC0・クレジット不要。Ben Jaszczak ほか）の録音を、**加工せずそのまま**使う（`dev/assets/sfx/`、ステレオ44.1kHz。96kHzから変換しても聞き分けられないことをユーザーが確認済み）。HG=Springfield 1917 の B_16P（2発）、SG=Winchester Model 12 の K_22P・K_17P（4発）、MG=AK-47 の C_28P（4発）は、元の余韻と反響を含めて1.2秒を使う。SMG=Carl Gustav M45 の G_35P は連射の1発ずつ（約93ms、9本）に、連射の最後の1発（余韻つき、2本）を加える。MGの連射用には C_27P の連射から約90msの1発を6本。直前の発射から0.2秒未満なら短い1発、それ以外は余韻つきの長い1発を選ぶ（連射で余韻が積み重ならないように）。加工は、音の頭のプツッを防ぐ1.5msのフェードイン、末尾のフェードアウト、音量合わせ、保険のリミッターだけ。左右の幅・低音・圧縮・残響は触らない。元のファイルと並べて聞いて「元（無加工）が良い」とユーザーが選んだため。URLに `?snd=body` を付けると低音の持ち上げ＋1オクターブ下の層を足した版、`?snd=full` で以前の濃い加工版、`?snd_debug=1` で鳴った武器とテイク名を画面左下に表示。読み込めない間・失敗時は下の合成音に切り替わる
- 銃声（合成・予備）：作り直し。ゲーム共有のノイズは約115Hz以下しか出ない低音だけの音で、高音の破裂成分が鳴っていなかった。専用の白色ノイズで「瞬間の破裂→フィルタが高→低に落ちる本体→低音ドン」の3層に、歪み・コンプ・短い残響・こだまを足した。毎発ピッチ±8%・音量±10%で変化（測定：最初の60ms内の2kHz以上のエネルギーが HG 4%→19%、SMG 5%→33%）
- 命中：体は鈍い「ドスッ」＋血5粒、ヘッドショットは低い「ゴッ」を上乗せ（高い「キン」は廃止）＋赤い血14粒、撃破は血18〜26粒（頭は赤が濃い）。手動ヘッドショットの撃破だけ0.05秒のヒットストップ（オートエイム中の頭は対象外）
- 曳光：細い線をやめ、橙色の太い光弾が飛ぶ（明るい砂色の背景で消えていた加算合成をやめ、距離に応じて太さを保つ）。SGは散弾4本
- 薬莢（SGは赤）は走行速度を引き継いで見える時間を延長。銃口の煙、フラッシュは不透明の黄色（0.06秒）
- 血・命中の閃光は距離に応じて大きさを保つ（15m先でも約10px）。被弾したゾンビは0.1秒赤く光り、撃破では命中マークが大きくなる
- 画面揺れ：SG 0.55・MG 0.3（動きの少ない設定では出ない）
- 未対応：連射で視点が戻らない件、銃モデルと弾道のずれ（別途）
