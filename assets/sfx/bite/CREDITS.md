# Bite / shove sounds — sources

All takes were cut from the CC0 (public domain dedication) packs below, found on OpenGameArt.org. The licence shown on
each page was read on 2026-11-03. CC0 needs no credit; this list is kept for traceability.
Rebuild with `python3 tools/build_bite_sfx.py SRC_ROOT assets/sfx/bite` (mono 44.1 kHz, 3 ms fade-in, fade-out, band-limited,
normalised, 64 kbps MP3).
