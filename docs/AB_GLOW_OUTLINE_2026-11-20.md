# 太陽グローと輪郭線の有り無し計測（2026-11-20）

## なぜ測るか
実機（iPhone・画質「高精細」・描画1266×585・影あり）の `diagnostics.perf` で、1フレームの間隔が11/9〜10の約18msから11/14〜17の約24〜27msに伸びた。ゲーム処理（CPU）は約10msのまま、差はGPU待ち（`iv − cpu`が約11ms→約15ms）。
11/11〜11/12に入れた見た目のうち、仕組みから見て重そうな順に **① 太陽グロー（`mood.js` の `Sun glow`、420mの加算スプライト、どの画質でも常時）** と **② 輪郭線（`ink-outline.js`、静的な建物を裏向きにもう一度描く、三角形 +約8%）** を、有り無しで測って除去するか決める。
時期が重なっているだけで原因は確認できていない（同じ期間にほかの更新も入っている）。

## 使い方（実機）
`https://jirisuke0121.github.io/gunrun-sky-proto/bench/ab-glow-outline.html` を横向きで開き、ボタンを押して約1分触らない。

- iframeで `index.html` を開き、ゲームを自動で始め、4条件（両方あり／グローなし／輪郭線なし／両方なし）の表示を切り替えながら描画間隔を測る。
- 1ラウンドで4条件を一巡し、順番をずらして6ラウンド。熱や時間経過の影響を、ラウンド内の差（対の差）で相殺する。
- 60fps上限に差が隠れないよう、1フレームに K=3 回ぶん余計に描画して差を4倍にし、結果は4で割って「1回の描画あたり ms」で出す。
- 差が±ばらつきより小さい（t<2）ときは断定しない。目安：1ms以上＝大きい（除去する価値あり）、0.3〜1ms＝小さい、それ未満＝誤差。
- ゲーム本体は変更しない。プレイ記録は送らない（ゲームは終了させず、計測中は iframe の `fetch` / `sendBeacon` も止める）。
- 画面が隠れる・タブが止まって描画タイマーが止まった区間（間隔400ms超、`?stall=`で変更）は除外して数え、無効なラウンドは落とす。有効が3ラウンド未満なら判定しない。
- 調整：`?slice=1500&rounds=6&k=3&settle=300&stall=400`。

## 確認範囲
- ヘッドレスChrome（ソフトウェア描画・480×270・短い設定）で最後まで走り、結果の形式とPOSTが0件であることを確認。この環境の数値はGPUの代わりにならない。
- 実機の数値は未取得。結果が出たら、効果が大きいほうだけ除去（または画質「軽量」で切る）する。
