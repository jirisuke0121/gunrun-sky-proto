# 移動方向へ追従し、手動の視点操作を外す比較試作

## 対象と判断基準

固定カメラ案から、元の移動方向に追従する簡単操作へ戻して比較する。今回は左スティックの変換、移動速度、地形、敵、自動照準・射撃を変えず、手動の視点操作だけを外す。短い実在の通路で継続して曲がる・戻る・ジャンプ中に修正する操作が自然かを評価し、成立を確認してから採用を判断する。

- 第1段階：右ドラッグ／マウスで視点が変わらず、右側の指が自動追従を止めない。二本指ジャンプ、空中の入力修正、既存の手動視点は維持する。
- 第2段階：通常開始・入門・リトライ・入門後の復帰で、選択した比較方式を保持し、過去の固定視点を混ぜない。
- 第3段階：同じ通路・入力を以前の追従式と比較し、人物が映るだけでなく進路と入力が対応するかを判断する。視点を回すために立ち止まることを解法にしない。

## 比較用の指定

`?camera=after&cameraTrial=follow` が手動視点を受け付けない比較版。`cameraTrial=follow-legacy` は以前の「自動追従＋手動見回し」。`camera=before` は従来の手動視点。`bench/auto-follow-review.html` で同じ場所から切り替える。

手動視点なしの方式は、この段階では比較用の指定で有効にする。通常の追従式を一律に置き換えない。以前の `gunrun-fixed-controls-v1` による暗黙の固定視点復元と、入門で固定視点を強制する処理は外した。明示した固定・区間カメラの比較は保持する。

## 実装と検証

- `follow-camera.js`：比較版のlook入力を処理済みとして受け取り、視点へ反映しない。右指が触れていても自動追従を続ける。移動入力は以前と同じ。PCの既定・保存済みの手動操作を変更しない。
- `guided-preferences.js` / `guided-intro.js`：固定試作の保存フラグを削除し、通常起動では固定試作を復元しない。明示した比較方式だけを入門・本番復帰へ引き継ぐ。
- ホーム・遊び方・入門の表示：自動追従と手動見回しを区別。比較版にマウスや右ドラッグの案内を出さない。日英の文言と読み込み版を更新する。
- `bench/follow-camera.test.cjs` / `bench/auto-follow-routing.test.cjs`：手動入力の抑止、追従の継続、既存の移動・特殊動作、保存設定・URLの引き継ぎ。
- `bench/auto-follow-browser.cjs`：両マップ×以前／比較版をChrome DevTools Protocolのタッチ入力で操作する。物理端末の入力ではない。二本指ジャンプ・空中修正の機能確認と、通路の操作評価を区別して記録する。
- `bench/auto-follow-entry-browser.cjs`：通常開始、日英の遊び方、リトライ、入門の実ボタン、実移動で最初の課題通過、練習を終えるボタンから元マップへ戻る流れを確認する。全入門課題の完走を意味しない。
- `bench/auto-follow-review-browser.cjs`：PC・タッチで方式・マップ切替と実プレイ。`bench/pc-controls-browser.cjs`：既存PC操作と保存設定の回帰確認。

## 最初の比較で分かった問題

右ドラッグ80pxで、以前の方式は約25.7度回転し、比較版は0度だった。比較版では右指を置いても自動追従が続き、二本指ジャンプと空中の入力修正も届いた。

一方、**移動入力はそのままなので、連続した曲がり方の課題は残る**。旧市街の西入口 `(-15.5, 0, 0)` から東へ入り、左入力で北へ曲がった後、指を離さず上へ戻すと、現在の画面の前方ではなく元の東へ向いて壁に当たった。入力直前の画面の前方に対する方向差は約88.9度。約0.58秒の上入力で移動距離は約0.25m、その間に東へ進んだ距離は0mだった。以前の方式と比較版の移動結果は同じ。

これは技術的な入力試験の成功とは別の、操作評価の不合格。**このまま全体へ採用する判断はしない。** 次の課題はカメラの固定や切替ではなく、追従中に上へ戻した指と進行方向の対応である。

画像・入力列・各フレームの位置・視点・停止状態は `browser-evidence/auto-follow/`。ここで使用した場所は既知の北側上階・西廊下の固定点であり、直近の写真のプレイヤー座標を厳密に同定したものではない。敵を除いた操作比較で、物理iPhoneの操作感、初見プレイヤーの理解、追手のいる連続逃走は未確認。

## ローカル検証結果

| 段階 | 結果 | 証拠 |
| --- | --- | --- |
| 手動視点を無効化・追従継続・二本指ジャンプ・空中修正 | 合格 | 両マップ×以前／比較版、`results.json` |
| 通常開始・日英の遊び方・リトライ・入門と本番の往復 | 合格 | `entry-results.json`、既存の入門選択・停止・ジャンプ案内12条件 |
| 比較画面の方式・マップ切替、PC／タッチの実移動 | 合格 | `review-results.json` |
| 従来のPC・タッチ操作 | 合格 | `pc-controls-browser.cjs`、`easy-controls-browser.cjs` |
| 西廊下で曲がってから上入力へ戻す操作 | 不合格・未採用 | `assessment.json`、`follow-index-west-door-1.png` と `-2.png` |

単体検証は `follow-camera`、`auto-follow-routing`、`onboarding`、`next-step`、`hook-touch-exits`、`stair-walk`、`player-skills`、`human-view-running` が合格。容量は17.54MB（20MB目安の88%、50MB上限の35%）。CI・公開先での確認は行っていない。

## ローカルで比較する

リポジトリ直下から `python3 -m http.server 8895 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8895/bench/auto-follow-review.html` を開く。「視点は自動」→「中央建物・西入口」→「ここから遊ぶ」で、上へ進む→左へ曲がる→指を離さず上へ戻す。同じ入力を「以前の簡単操作」で比較する。比較画面は敵なし・無敵・記録送信なし。「通常の開始から遊ぶ」は選択した比較方式を保った通常のゲームで、操作比較画面とは条件が異なる。
