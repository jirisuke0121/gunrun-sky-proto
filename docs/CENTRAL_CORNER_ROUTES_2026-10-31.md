# 中央建物の角を使う逃走分岐

南の踊り場と北側バルコニーから、鉄棒で西側の縁へ渡る2経路を追加。④の柱分岐を参考に、空中の近道と、着地後の移動・追手の回り道を組み合わせる。

| 経路 | 入口・鉄棒・着地 | 着地後 |
| --- | --- | --- |
| ⑤ 南の踊り場 | 踊り場4m → 鉄棒 `[-8.6,6.8,17]` → 南西の縁4.2m | 西壁に沿う階段で既存通りへ。既存の西屋根フック `[-18,9.8,5.5]` も範囲内 |
| ⑥ 北バルコニー | バルコニー4m → 鉄棒 `[-5.7,6.8,-15.5]` → 北西の縁4.2m | 西壁沿いの階段で既存通りへ。フックを使う場合は縁の南側へ進む |

- 南の踏切は既存階段の手すりを避けてZ17に置く。北は西端の手すり中央だけを開け、短い踏切を追加。踏切の南端をZ-15.1までにして、(0,-14.54)の屋上梯子を空ける。
- 縁から西通りへの階段は0.3m刻み。追手も歩いて回り込める寸法で配置。実際のナビグラフ・追手の実動作は未確認。
- 南の下には既存の階段・街路がある。北の隙間には高さ-3.5mの復帰床と既存西通りへ上る0.35m刻みの階段を追加。すべての落下角度を救済するものではない。
- ④の既存鉄棒6本・フック配列・梯子・移動能力・鉄棒物理は変更しない。新しい鉄棒2本は配列末尾へ追加。
- スタート画面に⑤⑥の練習入口を追加。`?oldtown_swing=1&swing_route=south-corner` / `north-corner`。この入口の記録は送信しない。

## 検証範囲

`node bench/central-corners.test.cjs` は、実際の地形生成と `createSwing` の掴み・振り子・離脱処理を使用する描画なしの検証。通常の空中区間は重力20m/s²、ジャンプ初速7.2m/s、水平初速6m/sと逆入力14m/s²の限定モデルで、完全なゲーム実行ではない。

- 離脱角0.55 / 0.65 / 0.8rad × 横ずれ-0.35 / 0 / +0.35m × 2経路の18例で、1回の掴みと離脱から4.2mの縁への着地を確認。
- 鉄棒なしの比較では縁へ到達しない。
- 着地から西通りまで10cm間隔で床・段差・立位の空間を確認。足元42cmの段差処理に相当する領域は除いて上半身の空間を検査。
- ④の3連の座標と西屋根梯子の空間を照合。
- 既存の鉄棒タイミング、前宙、斜面滑り、タッチフックのテストを実施。

確認用ブラウザでWebGLコンテキストを作成できず、ゲーム本体が初期化されなかった。画像と座標の厳密な照合、フルゲームの通し移動・逆方向移動、追手の到達、iPhoneの指操作と逃走バランスは未確認。配置は画像から南側踊り場／北側バルコニーと推定したもの。
