## 壁キックの吸い戻し（ゲーム側の不具合。直した）

- 症状：リング西壁（中央ブロックの西面）を北へ壁走りして、**窓の下（z −12.9〜−11.1）で壁キックすると、0.1秒後に壁へ吸い戻される**（0.44 m 瞬間移動し、外向きの速さが消えて壁走りに戻る）。踏み切りの範囲（z −15.6〜−11.6）の北寄り約1/3で起きる。
- 原因：11/11 の窓破りダイブで壁に窓を開け、壁の箱が3つに分かれた。壁キックの直後は「同じ壁にはすぐ付き直さない」決まりだが、その「同じ壁」を箱の番号で見分けていたので、隣の箱を別の壁と見なして付き直していた。
- 直し：`wall-jump-spots.js` に `__skyWallFaceKey` を足し、`run`（壁面の範囲）のある経路では、箱が違っても同じ1枚の壁面として見分ける。`index.html`・`canyon.html` の見分けの1行をこれに差し替え（無ければ従来どおり箱の番号）。今のところ該当するのはリング西壁だけ。
- 確認：`north-wall-browser`（PC・タッチ、高さ3通り × 位置3通りの壁キック）・`wallrun-permissions-browser`・`window-dive-browser`・`return-links-browser`・単体87本が成功。
- 順位対象の難易度でも効く変更だが、11/11 より前の動きに戻す直しなので、ランキングの版は上げていない（v15 のまま）。戻すなら `index.html` の `window.__skyWallFaceKey?.(l,h)??` を消す。
- 物を足して壁を分けるとき（窓・入口）は、壁走りの許可面なら `run` を付ける。付けないと同じことが起きる。

## escape-branch-audit（直した）

- 落ちていたのは `east-lower-escape-with-pursuers`：東端デッキ（3.6 m）の西端から跳んで、低い通路（−1 m）へ降りて逃げる想定。
- 実際は、走りジャンプ（約4.3 m）が **11/10 に足した張り出し（`return-links.js` の `LIP`、高さ3 m、x 46〜48）に必ず着く**。張り出しは「デッキ → 跳ぶ → 台 → 南の屋根」と戻るために足した物で、これが今の設計。縁は歩いて降りられない（`edge-assist.js`）ので、検査の人形は張り出しの角で止まっていた。
- つまり地形は設計どおりで、検査の想定が張り出しより前のままだった。`?prune=0&links=0`（11/22の改装前の地形）でも同じ位置で止まるので、改装は無関係。
- 直し：想定を今の設計に合わせて `east-deck-escape-with-pursuers`（デッキ → 張り出し → 西の3 mの台、追手2体つき）に置き換えた。旧市街・渓谷 × PC・タッチの全156件が成功。
- 東端デッキから低い通路（−1 m）へは直接降りない（跳べば張り出し、歩けば縁で止まる）。**意図どおり**（本人に確認、11/22：落ちやすいので、歩くと降りられない・跳べば降りられる、にしてある）。

## 行動通知の小画面（11/22 の直しの余裕）

`#actionFeedback` を7言語 × 幅640・568（高さ320）で測った。CI に近い幅広の字（DejaVu Sans）でも測った。上限は画面高の68%（217.6px）。

- 日本語・英語・タイ語・ベトナム語・ポルトガル語・トルコ語：640 幅で最大4行、下端 約190〜207px。収まる。
- **スペイン語だけ余裕が薄い**：いちばん長い文（閃光玉0個）が幅広の字で 640 幅 4行（下端207px）、568 幅 5行（下端222px、5pxはみ出す）。入門中は左上の難易度の札がスペイン語で3行になり、通知の始まりが18px下がるため。
- 568×320 は初代 iPhone SE 相当でほぼ無い。今の対象（PlaytestCloud・Y8、英語）では問題なし。スペイン語を主に出すときは文を短くする（`docs/I18N_2026-11-13.md` の手順）。
