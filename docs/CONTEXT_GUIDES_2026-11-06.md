# 実コースの場面別案内

## STEPと完了条件
1. ネイティブの発動条件を参照し、使えない場所・隠れた操作・他の案内と競合する場合は出さない。
2. 入門の実コースで対象・既存ボタンを強調して停止。既存入力だけで本来の処理を動かし、発動の実績で成功判定する。
3. 単体で各条件・保存・競合・通常ラン除外を検証し、ブラウザで実際の入力と敵・時間の停止／再開を確認する。

|案内|タイミング|完了条件|
|フック|既存の射程・画面内・遮蔽物・クールダウン判定に合う地上地点|実フック発射|
|壁走り|登録済み有効壁の1.8m以内・進行方向が壁沿い・画面内|実際にwallrun状態へ移行|
|壁ジャンプ|壁走り中、登録済みの壁ジャンプ可能地点|walljumps実績が増加|
|ジップライン|本来の出発側つかみ範囲（水平2.3m・高さ0.8〜3.4m下）|実際にzip状態へ移行|
|斜面滑り|実際のcanStartが真、タッチならボタンも表示中|slide状態へ移行|
|爆破ジャンプ|本来のassistTargetが使える時|本来の自動接近・爆破シーケンス開始|
|閃光玉|残数あり、有効範囲8m内・同じ階付近・遮蔽物なしに有効な追手2体以上、うち1体以上が4m以内|投擲数増加（命中や撃破は要求しない）|
|分身|有効範囲16m内に見える有効な追手2体以上、うち1体以上が4m以内、クールダウン終了、実際に設置可能な足場あり|実発動数増加|
|救済|追手4m以内、閃光玉なし、分身再使用待ち、残数と安全な行先がある|実残数が減少|
|乗り越え・よじ登り・壁走り|初回の実成功|自動動作なので止めず成功通知のみ|

追手2体・危険距離4m（既存の救済案内と同じ近距離判定）・案内間隔8秒はゲームバランスの変更ではなく、入門の案内を出すための初期ルール。閃光玉・分身の範囲は実設定に合わせる。遠い敵が複数いるだけでは消耗スキルを案内しない。気絶・閃光停止・分身への誘導・復帰待ち中の敵は閃光玉／分身の危険判定・対象数から除外する。鉄棒・はしごは案内対象から除外し、停止させない。案内に必要な操作が失敗した場合、成功扱いにせず、移動試行が2.5秒を超えたら通常へ戻す。空中で見本や確認ボタンを操作させない。

全案内は初回成功をマップ別に保存。8ゲーム秒の間隔とフック案内との排他で連続表示を防ぐ。「閉じる」はそのランだけ対象を除外。通常の順位対象ラン・練習場・オーナー再生は対象外。`?guides=1`で入門の全案内を再表示、`?guides=0`で無効。自動ブラウザでは明示指定時だけ有効。

追加の光源・動画・移動ボタン・地形・発動代行はない。描画はDOMの輪と短文だけ。
