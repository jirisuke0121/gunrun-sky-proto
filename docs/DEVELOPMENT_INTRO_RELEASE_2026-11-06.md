# 開発用の入門を通常URLへ反映 — 2026-11-06

ユーザーは比較の終了と変更版の更新を指示。入門を遊ぶボタンは、目立たない開発用の場所へ移す。

## 段階と完了条件

1. ホームで入門への自動転送と通常の初回入門案内を止め、下部の閉じた「開発用」に「入門モードで遊ぶ」を置く。両マップ・日英・スマホ横画面とPCで、通常の開始ボタンを妨げずにコースへ入れること。
2. LANのHTTPで利用できない `crypto.randomUUID` による初期化停止を直す。`getRandomValues` を使うUUID v4の代替を共通化し、通常ランの記録IDと独立した計測IDで使用する。安全な乱数源とID形式を維持し、APIがない条件でも人物・銃・実行拡張の準備が完了すること。
3. 現在のGitHub mainを取り込み、カメラ感度1.7の更新を維持する。CIと公開後のHTTPSページで、主な入口・読み込み・入門の操作を確認する。

通常のゲーム開始が主導線。新しい連続入門は開発用として公開する。通常のホームを開くだけでは入門へ転送しない。入門を開いて操作を確定した後は、従来のローカル試作と同じ方式保存と本番への接続を維持する。

`?onboarding=auto/1/reset` は従来の2分間入門の明示的な確認用経路。既存の戦闘・結果の試験は、このモードのDOMボタンをプログラムから起動してフィクスチャとする。通常ユーザーの入口は新しい開発用ボタンの実クリックで試験する。

比較用のページを本番に追加しない。ゲームの通常のGitHub Pages URLを更新する。
