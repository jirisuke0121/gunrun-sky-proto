# 意図しない落下の原因と、緊張→解放の循環の計測（2026-11-11）

旧市街・スマホのかんたん操作（画面の向きへ倒す）で、実ゲームの物理・カメラ・追跡AIを動かして測った。人のプレイではない。

## 1. 意図しない落下

### 測り方

- 経路データにある屋根から屋根への跳び移り（5.7 m以下、助走3 mが取れるもの）を、踏切の場所と向きごとに1本ずつ、106か所。
- 3 m手前から親指を前に倒したまま走り、縁の 0.5 / 0.25 / 0.05 m 手前でジャンプを押す（縁ぎりぎりの、自然な押し方）。早押し（2.5〜0.75 m手前）も比べた。
- 途中で鉄棒・ジップ・はしごに乗る18か所は別扱い。残り88か所が「ただの跳び移り」。

### 分かったこと

| 原因 | 数 | 内容 |
|---|---|---|
| **跳び越え** | 縁ぎりぎりの失敗46回のうち43回 | 走りジャンプは4.3 m以上飛ぶ。隙間は1〜2 m、着地の足場は奥行き1〜2 mの所が多い。縁で押すと隙間も足場も越えて、1段下（2 m以上下が38回）へ落ちる。88か所中22か所で起きる。うち11か所は「縁の0.75〜1.5 m以上手前で押したときだけ」着地できた |
| 届かない | 46回のうち3回 | 1か所だけ（西の高い屋根 15 m、隙間4.25 m） |
| **はしごに連れて行かれる** | はしごの上8か所・15回中15回 | はしごの上の縁へ走ると、縁の1.3 m手前で自動的にはしごへ移り、通りまで降りる。縁の0.3 m手前でジャンプを押すつもりの走りは、押す前に全部はしごへ取られた |
| 縁のブレーキで踏切が遅くなる | 影響は小さい | 縁の1.1 m手前から速さが落ち、縁ぎりぎりでは3.4〜4.6 m/sで踏み切る（走りは6 m/s）。ただし空中で加速が戻るので、着地の成否はほぼ変わらない（51本で±2本）。直していない |

走っているだけ（ジャンプを押さない）で屋根から落ちる例は、はしご以外には見つからなかった。縁の補助（`edge-assist.js`）は効いている。

### 直したもの

1. **着地の補助**（`edge-assist.js`）。ジャンプ中、いまの速さだと「踏切と同じくらいの高さの屋根（上0.5 m〜下1.5 m）の上を通り過ぎて、そこより1.2 m以上低い所へ落ちる」ときだけ、前への速さを落としてその屋根の奥の端の0.3 m手前に降ろす。
   - 触らないもの：同じ高さの屋根にそのまま届くジャンプ、空中で向きを変えたとき（親指が進行方向から60°以上それる）、ジャンプ台・爆風・DASHなどの打ち上げ、鉄棒・ジップへ届くジャンプ、壁やひさしに当たる軌道。
   - 速さを足すことはない（落とすだけ）。`?landAssist=0` で切れる。
2. **はしごの上**（`escape-routes.js`）。走ってきた勢いのままでは移らない。縁で止められて（速さ2.5 m/s未満）外向きに0.2秒押し続けたときだけ、はしごへ移る。

残る8か所（一部の押し方で跳び越える）：東塔の階段状の梁（x 27〜31、z -5→-8）、西の5.5 mの柱（x -30、z 0）、西の3 m→1.8 mの段（x -41、z -10）など。足場の高さが段々に変わる所で、補助が「同じ屋根」と見なせない。

### 確認していないこと

- 人が遊んだときの感じ（空中で前へ進む速さが落ちるのが気になるか）。iPhone実機。
- 模型の親指は空中で離さない・引かない。空中で親指を引いて自分で縮める人には、補助は働かないことが多い（親指が後ろなら「向きを変えた」扱いで外れる）。
- わざと足場を跳び越えて下の段へ降りたい場合は、補助がその足場に降ろす。降りたいときは足場の端から歩いて降りる／跳び直す必要がある。

## 2. 緊張→解放の循環

### 測り方（`node tools/chase-respite.cjs`）

- 追手1体を3 m後ろに置き、跳び移り（上で着地できた踏切のうち、後ろに追手を置ける29か所）を跳んで、0.5秒走って止まる。**着地から最初に噛まれるまでの秒数**を「猶予」とした。
- 追手の速さは難易度表（`CHALLENGE_DIFFICULTY.md`）の中ほど：イージー5.4、ノーマル6.4、ハード7.4 m/s（人は6 m/s）。平らな通りで実測して合わせた。
- 仕掛け（ジップ・鉄棒・大スイング・窓破り・塔のトンネル）は、踏切に置いた追手が、着地点に立つ人を噛むまでの秒数から、人がその仕掛けにかかる秒数を引いた。

### 結果

| 動き | 猶予（ノーマルの速さ） |
|---|---|
| 平らな所を走る | イージーは追手のほうが遅い（差 0.6〜1.7 m/s）ので、走るだけで離れる。ノーマルは0〜0.8 m/s、ハードは0.8〜2 m/sずつ詰められる |
| 屋根の跳び移り（29か所） | 中央値2.2秒（イージー2.4、ハード2.0）。3秒以上は29か所中7か所、6秒以上は3か所 |
| 鉄棒（8ルート） | 1.7〜14.0秒（中央値 約4.4秒。人の所要を3秒と置いた見積もり） |
| ジップ（計測できた2本） | 6.4秒、13.1秒 |
| 大スイング | 5.5秒 |
| 塔のトンネル | 5.0秒 |
| 窓破りダイブ | 13.0秒 |

### 読み取れること

- **ふつうの跳び移りでは振り切れない。** 追手は同じ隙間をすぐ渡ってくる。1回の跳び移りで稼げるのは約1秒ぶん（止まって2秒で噛まれる）。跳び移りは「差を保つ」動きで、「解放」にはならない。
- **数秒の解放が出るのは仕掛けの所だけ。** 4秒以上の差が付くのは、鉄棒・ジップ・大スイング・トンネル・窓破りの計13か所前後。循環（追い詰められる→連続パルクール→振り切る）は、プレイヤーがこの13か所へ向かう道を知っているときにだけ回る。
- **イージーは緊張が弱い。** 追手が人より遅いので、囲まれない限り走るだけで逃げられる。パルクールを使う理由が薄い。
- ハードは平地で毎秒0.8〜2 m詰められる。跳び移りの1秒（約6〜7 m）は3〜8秒で消える。

### 確認していないこと

- 追手が4〜8体いて、前や横からも来る3分の通しでの波。上は「1体が真後ろ」のときの下限。
- 銃・閃光玉・分身・救済ボタンを使ったときの猶予。
- 人のプレイ。**プレイ記録には1秒ごとの「いちばん近い追手までの距離」が既に入っている**ので、実プレイで循環が回っているかは記録から数えられる（下）。

### 実プレイの記録で数える（`tools/telemetry/analyze_chase.py`）

```sh
cd server
npx wrangler d1 execute gunrun-runs --remote --command 'SELECT json FROM runs ORDER BY received_at ASC' --json > runs-export.json
python3 ../tools/telemetry/analyze_chase.py runs-export.json
```

マップ・難易度ごとに次を出す。

- 追手が4 m未満（追い詰められている）／12 m以上（解放）の時間の割合
- 「5 m未満→12 m以上を3秒以上保った」回数（1分あたり）と、その長さの中央値。1回も無いプレイの数
- 記録された落下の数と、1秒で3 m以上高さを失った回数・場所の上位10か所（屋根から降りてしまう場所）

判定の目安：追い詰められている時間が50%超なら解放が足りない。解放が60%超なら緊張が足りない。振り切りが2分に1回未満なら循環が回っていない。`python3 tools/telemetry/analyze_chase.py --selftest` で計算の確認ができる。書き出したファイルには端末IDと操作の経路が入るので、リポジトリには入れない。
