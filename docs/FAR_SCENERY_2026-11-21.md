# 遠景：雲海・丘の村・城・山（2026-11-21）

`far-scenery.js`（新規）。旧市街の外と下に、見た目だけの景色を足した。`?scenery=0` で前の見た目（紫の建物の輪・宙に浮いた丸屋根）に戻る。`?mood=noon`・`?look=classic` では出ない。渓谷は対象外。

## なぜ

参考にした2本のリール（低ポリの草原と家／夕焼けの和風の都）の魅力は、走る足場ではなく**プレイ範囲の外**にあった：どこからでも見える山と塔、地平線まで続く屋根、空の色。
空中回廊は、マップの端の先が霧だけで、紫の箱の輪と、土台のない丸屋根（`enhancements.js`）が宙に浮いていた。マップは作り直さない（ルート・振り子・復帰ロープ・詰み地点のデータを残す）。

## 何を足したか（1メッシュ・色だけ）

旧市街は柱の上に立ち、足元は**雲海**。遠くの丘が雲から島のように出ていて、村と花の木がある。朝日の真下の峰に**城**（目印）。地平線は山の輪で、朝日の方角だけ谷にして太陽を隠さない。

| 何 | どこ | 備考 |
|---|---|---|
| 雲海（平らな円盤＋雲の山46か所） | 高さ −34（落下判定 −22 より下） | マップの真下にもある。柱は雲の中へ消える |
| 丘（島） | 中心から150 m以遠 | 190 mまでは高さ −9 以下（街の床より下）。それより遠くで高くなる |
| 村26・家137・塔・花の木 | 185 m以遠 | 壁の色は旧市街と同じ系統、屋根はスレート |
| 城 | 朝日の方角 250 m、峰の上 | 夕方（`?mood=dusk`）でも太陽の方角へ付いていく |
| 山の輪 | 300〜408 m | 遠いほど薄紫に霞む |

光は作るときに1回だけ計算して色に焼き込む（朝日側は暖かく、反対側は青紫）。実行時の光・影・霧・テクスチャの計算はない。

## 「あそこ行ける？」と思わせないルール

11/14の父のテスト（乗れないのに乗れそうに見える石ブロック）を繰り返さないため。検査（`bench/mood-browser.cjs` の 2b）で数値を固定している。

1. **切れ目**：中心から150 m以内（マップの半分の長さは約66 m）は雲だけ。陸は150 mから。
2. **下に置く**：雲の上面（−34）は落下判定（−22）より下。180 m以内は、家・木も含めて街の床（0）より低い。
3. **描き方を変える**：遠景には輪郭線を付けない（輪郭線は当たり判定の箱だけ）。遠いほど霞ませる。黄・橙（目印色）は使わない。
4. **人で確かめる**：初めての人に見せて「あそこ行ける？」と1回でも聞かれたら直す（未実施）。
