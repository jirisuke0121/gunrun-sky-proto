# パルクールの爽快感：技をつなぐ手応えと、ギャップ自動ジャンプの試作（2026-11-10）

## 見直しで分かったこと

- 速さの演出（集中線・走行時の画角+16°・カメラの引き・風切り音）は既に入っている。走る速さは6m/s。
- 乗り越えは進入の速さを保ったまま出る。よじ登りは速さの80%で出る。**技そのものでは流れは止まっていない。**
- 足りなかったのは次の3点。
  1. **つないだことへの反応がない。** 乗り越え→ジャンプ→スライドと続けても、1つずつ単発の音が鳴るだけ。
  2. **空中が地味。** 画角は水平の速さだけで決まり、跳んでいる間の変化がない。着地点も見えにくい。
  3. **縁で止まる。** 落下防止の補助が、ジャンプを押さない限り縁でブレーキをかける。走っているだけでは屋根の切れ目を越えられない。

技は17種類以上あり、11/1の整理どおり「技の数に、つなぐ気持ちよさが追いついていない」状態。**新しい技は足さず、つなぎを足した。**

## 入れたもの（既定で有効・見た目と音だけ）

`flow-feel.js`。速さ・ジャンプ力・重力・敵・スコア・ランキング規則は変えていない。

| 項目 | 内容 |
|---|---|
| FLOW（連続） | 技から3.2秒以内に次の技を出すと連続数が増える。2連続目から画面上部に「FLOW ×n」と残り時間の線を出す |
| 音 | 連続するたびに音階が1段上がる短い音（9段まで）＋風切り音。4連続から1オクターブ上を重ねる |
| 画面 | 連続した瞬間に画面の縁が一瞬光る。連続数に応じて画角が最大+3.5°、カメラが最大0.15m引く |
| 空中カメラ | 跳んで0.16秒後から画角が最大+4.5°、カメラが0.4m引いて0.2m上がる（着地点が見える）。着地で素早く戻る |
| 連続の終わり | 走るだけの時間が3.2秒続く／0.7秒立ち止まる／噛まれる／落下。空中・フック・ジップ中は時間を減らさない |

連続に数える動き：乗り越え、よじ登り、スライド、壁走り、壁ジャンプ、フック、ジップ、鉄棒の離し、踏みつけ、縁つかみ、くぐり、すり抜け、ジャンプ台、ドカン、ジャンプ銃、塔トンネル、**2m以上の空間を跳び越えたジャンプ**。その場のジャンプは数えない。

`?flowFeel=0` で全部消える。「視差効果を減らす」設定の端末では縁の光を出さず、画角の変化を4割にする。

## 試作：ギャップ自動ジャンプ（既定は無効、`?autoJump=1`）

走っているだけで屋根の切れ目を越える。ジャンプボタンは従来どおり使える。

- 条件：立って走っている（速さが走りの80%以上、体の向きと進む向きがほぼ同じ）／1.2m以内に足場の切れ目がある／切れ目の先1mに足場がない（段差や隙間ではない）
- 通常のジャンプの軌道を先に計算し、**3m以内の落差で、着地後に0.45m以上走れる足場に届くときだけ**跳ぶ。途中に壁や庇があれば跳ばない。
- 跳ぶと決まった間は、縁の手前のブレーキを外す（助走の速さを保つ）。

### 計測（旧市街、`node bench/flow-feel-browser.cjs`）

マップの経路データにある「跳び移り」570本から64本を等間隔に選び、3m手前から前入力だけで走らせた。ジャンプは押さない。

| | 向こう側に着いた | 落ちた | 自動で跳んだ |
|---|---|---|---|
| 試作なし | 23本 | 0 | 0 |
| 試作あり | 45本 | 0 | 29回 |

残り19本は通常ジャンプの届く距離（約4.3m）を超えるため、跳ばずに縁で止まる。

### 既定にしていない理由

AGENTS.md の核「高台は跳び移りの技術が要る」と衝突する。跳ぶタイミングと踏切位置の技術が要らなくなり、上手い人との差が縮む。
入れるなら「かんたん操作のときだけ」「入門とイージーだけ」などの線引きが必要。実機で触ってから決める。

## あわせて直したもの

11/10の操作変更で、フックの到着時に親指を横へ倒したままだと、到着の0.2秒後に横へ走り出して足場を外れる例があった（`bench/hook-landing-browser.cjs` のスマホ1件）。
はしご・ジップ・フックなどから出たあと、**親指を動かしていない間は出た向きを保つ**ように変更。15°以上動かすと画面の向きへ切り替わる。

## 確認していないこと

- 物理スマホでの見え方・音量の釣り合い。FLOWの表示位置（上部中央）が邪魔にならないか。
- 追手がいる通しプレイで、連続数がどのくらい出るか（記録には送っていない。`document.body.dataset.skyFlow` に出しているだけ）。
- 自動ジャンプは旧市街の経路データでのみ計測。渓谷、追手がいる状況、スライド中・下り坂からの踏切は未計測。
