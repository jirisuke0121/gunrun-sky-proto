# パルクールの爽快感：技をつなぐ手応えと、ギャップ自動ジャンプの試作（2026-11-10）

## 見直しで分かったこと

- 速さの演出（集中線・走行時の画角+16°・カメラの引き・風切り音）は既に入っている。走る速さは6m/s。
- 乗り越えは進入の速さを保ったまま出る。よじ登りは速さの80%で出る。**技そのものでは流れは止まっていない。**
- 足りなかったのは次の3点。
  1. **つないだことへの反応がない。** 乗り越え→ジャンプ→スライドと続けても、1つずつ単発の音が鳴るだけ。
  2. **空中が地味。** 画角は水平の速さだけで決まり、跳んでいる間の変化がない。着地点も見えにくい。
  3. **縁で止まる。** 落下防止の補助が、ジャンプを押さない限り縁でブレーキをかける。走っているだけでは屋根の切れ目を越えられない。

技は17種類以上あり、11/1の整理どおり「技の数に、つなぐ気持ちよさが追いついていない」状態。**新しい技は足さず、つなぎを足した。**

## 入れたもの（既定で有効・見た目と音だけ）

`flow-feel.js`。速さ・ジャンプ力・重力・敵・スコア・ランキング規則は変えていない。

| 項目 | 内容 |
|---|---|
| FLOW（連続） | 技から3.2秒以内に次の技を出すと連続数が増える。2連続目から画面上部に「FLOW ×n」と残り時間の線を出す |
| 音 | 連続するたびに音階が1段上がる短い音（9段まで）＋風切り音。4連続から1オクターブ上を重ねる |
| 画面 | 連続した瞬間に画面の縁が一瞬光る。連続数に応じて画角が最大+3.5°、カメラが最大0.15m引く |
| 空中カメラ | 跳んで0.16秒後から画角が最大+4.5°、カメラが0.4m引いて0.2m上がる（着地点が見える）。着地で素早く戻る |
| 連続の終わり | 走るだけの時間が3.2秒続く／0.7秒立ち止まる／噛まれる／落下。空中・フック・ジップ中は時間を減らさない |

連続に数える動き（11/10 午後に絞った。下の「何を連続に数えるか」参照）：走りながらの乗り越え・よじ登り、スライド、壁走り、壁ジャンプ、フック、ジップ、鉄棒の離し、踏みつけ、すり抜け、パッド・爆風・ジャンプ銃の打ち上げ、タワーのトンネル、**ジャンプで3m以上の空中を越えた着地**。

`?flowFeel=0` で全部消える。「視差効果を減らす」設定の端末では縁の光を出さず、画角の変化を4割にする。

## 試作：ギャップ自動ジャンプ（既定は無効、`?autoJump=1`）

走っているだけで屋根の切れ目を越える。ジャンプボタンは従来どおり使える。

- 条件：立って走っている（速さが走りの80%以上、体の向きと進む向きがほぼ同じ）／1.2m以内に足場の切れ目がある／切れ目の先1mに足場がない（段差や隙間ではない）
- 通常のジャンプの軌道を先に計算し、**3m以内の落差で、着地後に0.45m以上走れる足場に届くときだけ**跳ぶ。途中に壁や庇があれば跳ばない。
- 跳ぶと決まった間は、縁の手前のブレーキを外す（助走の速さを保つ）。

### 計測（旧市街、`node bench/flow-feel-browser.cjs`）

マップの経路データにある「跳び移り」570本から64本を等間隔に選び、3m手前から前入力だけで走らせた。ジャンプは押さない。

| | 向こう側に着いた | 落ちた | 自動で跳んだ |
|---|---|---|---|
| 試作なし | 23本 | 0 | 0 |
| 試作あり | 45本 | 0 | 29回 |

残り19本は通常ジャンプの届く距離（約4.3m）を超えるため、跳ばずに縁で止まる。

### 既定にしていない理由

AGENTS.md の核「高台は跳び移りの技術が要る」と衝突する。跳ぶタイミングと踏切位置の技術が要らなくなり、上手い人との差が縮む。
入れるなら「かんたん操作のときだけ」「入門とイージーだけ」などの線引きが必要。実機で触ってから決める。

## あわせて直したもの

11/10の操作変更で、フックの到着時に親指を横へ倒したままだと、到着の0.2秒後に横へ走り出して足場を外れる例があった（`bench/hook-landing-browser.cjs` のスマホ1件）。
はしご・ジップ・フックなどから出たあと、**親指を動かしていない間は出た向きを保つ**ように変更。15°以上動かすと画面の向きへ切り替わる。

## 確認していないこと

- 物理スマホでの見え方・音量の釣り合い。FLOWの表示位置（上部中央）が邪魔にならないか。
- 追手がいる通しプレイで、連続数がどのくらい出るか（記録には送っていない。`document.body.dataset.skyFlow` に出しているだけ）。
- 自動ジャンプは旧市街の経路データでのみ計測。渓谷、追手がいる状況、スライド中・下り坂からの踏切は未計測。

## 何を連続に数えるか（11/10 午後に絞った）

「ジャンプすれば何でも付く」という指摘を受けて、旧市街で測った。目的は「意図して技をつないだこと」だけに反応すること。

測ったこと：旧市街の経路データの縁92か所（地上・乗り越え・飛び移りなど各種）へ3m手前から走り、縁の1m手前でジャンプを押した（使い捨ての計測。1回ごとに同じ結果）。

| | 連続が付いた縁 | 付いた動きの内訳（同じフレームに2つ付くと後の方だけ記録される） |
|---|---|---|
| 絞る前 | 88/92 | ギャップ70、乗り越え23、くぐり5、よじ登り3、スライド1 |
| 絞った後 | 91/92 | 乗り越え84、よじ登り5、ギャップ6、スライド2、くぐり0 |

- ギャップは70→6に減った（ジャンプで3m以上越えたものだけ）。ただし「付いた縁」は減っていない。**ジャンプを押すと近くの縁を乗り越える／よじ登る、というゲーム本体の仕組みで、乗り越えが付くため。** 絞る前はギャップが同じフレームの乗り越えを隠していただけ。
- くぐりは低い通路に走り込むだけで付いていた（地上の縁12か所中5か所）。縁つかみは、コードの上では壁際でジャンプするだけで付く。計測では出なかった。
- 乗り越えとよじ登りは、立ち止まった位置からでも付く（立ったままのよじ登りは進入速度0）。

絞った内容：

| 動き | 変更 | 理由 |
|---|---|---|
| ジャンプの着地（ギャップ） | **ジャンプを押していて、3m以上の空中を越え、落差3.5m以下、途中に足場なし**のときだけ。走って落ちる・段差を降りるだけは付かない | 絞る前は、走って落ちただけでも空中2m以上で付いた。3mは本体の「ギャップ」統計（3.5m）に近い線で、飛び移りの最短（約3.2m）を含む |
| くぐり | 対象から外した | 走り込むだけで付く |
| 縁つかみ | 対象から外した | 壁際でジャンプするだけで付く。失敗のリカバリで、技をつないだ結果ではない |
| 乗り越え・よじ登り | 直前フレームの速さが3.5m/s以上のときだけ | 立った状態からの上りは流れではない |

その場のジャンプ、押さずに空中へ出る、くぐり・縁つかみ、立ったままのよじ登りで連続が付かないことを D で確認する（平地のジャンプ連打は、絞る前から付かなかった）。

**残っていること**：乗り越えは「ジャンプを押せば近くの障害を越える」仕組みなので、縁の近くでジャンプを押すだけで付く。低い障害（高さ0.6m未満は旧市街の乗り越えの約4割）を外すかは未決。外すと「ただ跨いだだけ」が連続に入らなくなる。

## 着地のリングと土煙、3連続からの軌跡（11/10 午後）

見た目だけ。速さ・当たり判定・スコアは変えていない。`flowFeel=0` で消える。

- **着地**：空中0.3秒以上か落下速度4以上の着地で、足元に広がる薄いリング（強さで0.9〜1.7m、0.38秒）。落下速度7未満では小さな土煙も出す。7以上は `enhancements.js` に元々ある大きな土煙に任せる（二重にしない）。
- **軌跡**：FLOWが3連続以上の間、走っている・空中のときに、体の左右へ細長い光の筋を0.38秒ずつ残す。連続数が多いほど濃い。「視差効果を減らす」では出さない。
- **高い乗り越え**：乗り越えた障害の高さが1m以上のとき、低い重い音と小さな土煙を足す。低い乗り越えは何も足さない。旧市街で測った乗り越えの高さは0.36〜1.4m（中央値0.6m）。

### 作れなかったもの

- **片手の乗り越えモーション**：体のモーフターゲットが上限の256枚に達しており（実測256）、新しい乗り越えのポーズを足せない。足すなら既存のポーズを共有化して枠を空ける作業が先に要る。乗り越えは元々「乗り越え／よじ登り／縁つかみ」で別のポーズを使っていて、乗り越え時間も高さで変わる。今回は高さによる動きの違いを、音と土煙で出した。
- **キャラクターの残像**：人間モデルが7パーツ・256枚のモーフ付きで、複製を3体ぶん残すと描画が重くなる。代わりに光の筋にした。

### 確認していないこと

- 軌跡は旧市街の通常画面で薄く見える程度（`browser-evidence/flow-feel/trail-fx.jpg`）。スマホの画面で見えるか、うるさくないかは未確認。
- 渓谷でページエラーが出ないことだけ確認した。渓谷での見え方は未確認。
