## 実装と試行錯誤

初回訪問は早期に練習場へ入り、従来の開始カードと静的な2択ダイアログを挟まない。以後の「入門」も同じコースへ入る。操作体験中の方式変更は保存せず、確定した時に保存する。次回の通常ホームでも固定カメラ方式を復元する。

最初の足場は端から落下しない範囲へ制限。操作確定後はこの制限を外し、その場から本コースへ歩いて進む。案内は左端、操作選択は上端、確定ボタンは下端に置き、コース中の確定ボタンは即座に消す。練習中に関係のないスキルボタン・鉄棒の看板は隠す。

FPSも固定カメラも、同じ実キャラクター・衝突判定・ジャンプ・各技の発動条件を使用する。固定カメラの横入力が壁走り中に途切れる問題を修正した。フックは画面に見える有効な対象を選べるようにし、コースでは高い固定視点と位置調整でキャラクターと行き先を同時に映す。向きと画面方向の移動対応は固定のまま。

ジップライン・高台からの下りは成功した着地を再試行扱いにしない。斜面の踊り場に階段が干渉する箇所、斜面本体と復帰階段が重なる箇所を直し、地続きの復帰路を設けた。救済は屋根の下ではなく、本来の安全判定で高台を選べる地点から実行する。

## 課題の順序

移動 → 乗り越え → 隙間ジャンプ → 低いゲート → よじ登り → 壁走り → フック → 斜面への接近 → 斜面滑り → ロープへの復帰 → ジップライン → 壁蹴り → 鉄棒 → はしご → DASH → 踏みつけ → 飛び蹴り → 閃光玉 → 分身 → 爆破ジャンプ → ジャンプガン → 出口。旧市街に戻る場合は最後に救済。

閃光玉は実際に相手を止めたこと、分身は追手が誘導されている間に逃げ道の輪へ移動したことを判定する。無害な練習相手にも本来の追跡・分身誘導・閃光停止を使う。投げ損ねた時や分身が終了した時は、その課題内で再使用できるように戻す。練習での再挑戦用の補充で、本番の個数・再使用待ちは変更しない。
