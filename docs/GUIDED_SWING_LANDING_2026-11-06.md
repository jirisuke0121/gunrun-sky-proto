# 鉄棒で着地したのに開始位置へ戻る — 2026-11-06

## 原因と再現

入門の鉄棒課題は「鉄棒から2回飛び出し、X>133の足場へ着地する」を要求していた。一方、本体の鉄棒の成功表示は各回の飛び出しのタイミングを示すもので、入門の完了とは別だった。

最後の鉄棒からの通常のジャンプで、先の屋上(X=133.8265、Y=6.8001)へ着地しても、飛び出し回数が1回なので課題は未完了。そのまま次の低い足場へ跳ぶと、前の課題の床高判定が働き、X=119、Y=4.01の鉄棒手前へ戻された。再現では成功着地を確認し、さらに先へ跳んだ後に復帰が1回発生した。

## 修正と受け入れ条件

- 鉄棒から実際に飛び出し、着地点の屋上または接続先の屋上へ着地できれば完了する。表示していない2回という回数の条件を外す。
- 固定座標X>133ではなく、実際の足場の境界・高さと身体半径を使う。縁の正常な着地や、奥の接続屋上へ飛べた場合も完了として扱う。
- 鉄棒を使わない到達、空中、縁つかみ途中、下の床への落下は完了にしない。
- 完了後に落下しても、鉄棒完了を維持し、次の課題の足場へ戻る。

## 検証

回数と足場・身体状態の単体確認。最後の鉄棒へ入る初期状態だけをフィクスチャとして用意し、そこからは本来の鉄棒つかみ・ジャンプボタン・飛翔・着地で確認するブラウザ試験を追加した。初見の人の操作を再現したとする試験ではない。

カメラの両方式で、飛び出し1回の着地から次の課題へ進むことを確認。さらに、その後の落下でも鉄棒の手前へ戻らないことを確認した。従来の鉄棒2本を含むコース全体も、復帰0回で本番接続まで通過。
