## 2. 知っておくこと

- **gzip のモデル**：`assets/zombie-gunrun-standard.glb.gz`・町の人4種と遠景用・`zombie-near-indices.json.gz` は gzip。ゲームが `DecompressionStream` で展開する（`index.html`/`canyon.html` の `zGz`、`zombie-near.js`）。元のファイルは `pool/assets/`。作り直したら `gzip -9 -n -c pool/assets/X.glb > assets/X.glb.gz`。人のモデル（`human-gunrun-animated.glb.gz`）も前から同じ方式。
- **モデルの読み込みはゲームの乱数を動かす**（three.js が物を作るたびに id に `Math.random` を4回使う）。乱数を固定して結果を見る検査は、町の人と遠景用の読み込みが終わってから測る（`bench/zombie-types-browser.cjs` の待ち）。`character-look.js` の中は自前の乱数（`roll`）。
- 骨の名前：Unity は `Base Human…`、町の人は `mixamorigHead` のように `:` が消えた名前。両方に合う正規表現は `character-look.js` の `BONES`。
- 見た目を直すときは、先に近くから連続写真を撮る（`promo/video/shots.js` の `n_*`。`n_zline` 並んだゾンビ、`n_zface` 顔、`n_zladder` はしごを登るゾンビ、`n_bite` 噛まれる瞬間、`n_hface` 人の正面/背中、`n_run` 走り、`n_hook` フック）。撮影は `promo/video/engine.cjs <shot> W= H= FPS= EVERY= AUDIO=0 OUT=`（`promo/video/README.md`）。
