# フック後はどこか安全に着地できればよい

到着先はフック直下・同じ高さに限定しない。フックの勢いで別の屋上、下の足場、地面へ自然に着地できるなら、その移動を保つ。

## 動作

- 引き寄せ中の速度18m/s、加速、到着判定、上向きの弧は維持する。
- 自動解除時に、現在の水平速度と重力で着地する放物線を確認する。身体が壁・天井に触れず、落下終了位置より上にある実際の床を探す。
- 床がフック座標から水平2.5m以上離れていたり4m以上低かったりしても採用する。前版にあった位置・高さの制限は撤去した。
- 水平速度の修正量が少ない着地を優先する。そのまま着地できれば水平速度は変えない。同じ修正量なら先に着地する床を選ぶ。
- 入力を保持・変更した結果、別の床へ安全に着地できるようになれば、その床へ切り替えて勢いを保つ。最初に選んだ足場へ引き戻さない。
- 安全な自然着地がなければ、届く床へ向けて余分な勢いを補正する。座標は移し替えず、通常の重力と衝突処理で着地する。
- 通常のパルクールで雲梯などへ自然に掴まった場合も、その動作へ移行する。
- 手動ジャンプでフックを離すと補助を解除する。次のフック、通常ジャンプ、再配置／再スタートでも解除する。
- 壁に引っかかった解除、フック時間切れ、安全な着地弧がない場合の既存処理は維持する。共通フック処理を使う救済スキルにも適用する。

## 予測範囲と負荷

予測は最大2秒。実マップの高いフック解除位置（約16m）から下の床（-3.5m）まで、既存の上向き速度4.5m/s・重力20m/s²で降りる時間は約1.64秒なので、その自然な着地も候補に含める。前版の1.25秒ではこうした軌道を除外していた。

候補は速度×2秒の範囲に2.5mの余白を加えた周辺の床から収集し、修正量順に並べる。40ms刻みの身体の空間確認は、有効な軌道が見つかった時点で打ち切る。空中入力が現在の床を外す時は、収集済みの床に安全な自然着地があるかを確認する。

立ち位置の余白は身体半径+12cm。細い梁では中央まで縮める。補助の有効時間は予測範囲に150msの余裕を加えた2.15秒で、座標移動や滞空による救出は行わない。

## 検証

補助が適用された498試行のうち493試行が安全な床へ着地し、5試行は雲梯などのパルクールへ接続した。めり込み・ライフ減少はなかった。旧市街の共通53進入・無操作条件では、解除直後の平均水平速度が前版の4.94m/sから6.45m/sになり、着地できる範囲を広げることで余分な減速を減らした。実プレイヤーの落下率を示す数字ではない。

- `node bench/hook-landing.test.cjs`：下の離れた床へ自然に着地できる場合に速度を維持。空中入力で別の安全な床へ向かう場合も元の床へ引き戻さない。狭い床への補正、外向き入力保持、手動ジャンプ解除、障害物・床なしも確認する。
- `node bench/hook-landing-browser.cjs`：実際の両マップ、94進入×無操作／前進保持／横移動保持×デスクトップ／タッチ相当、計564試行。安全な着地と雲梯等への自然な接続を分けて記録し、引き寄せ最高速度・壁のめり込み・ライフ・手動ジャンプ解除を検証する。
- `node bench/free-hook-browser.cjs`：救済で高台へ着地すること、ゾンビからの距離、2回の使用制限。
- `node bench/hook-touch-exits.test.cjs`。
