# 見通しが悪い区間だけ切り替えるカメラ

基点 `f5a14a4`。作業ブランチ `codex/hybrid-camera-20261108`。ユーザーの公開依頼に基づいて反映する。試作は `?camera=after&cameraTrial=hybrid`、比較画面は `bench/hybrid-camera-review.html`。

## 要件と実装

| 要件 | 実装 | 確認方法 |
|---|---|---|
| 通常は固定、厳しい区間だけ別の方向へ | 頭・足元と2m先の見通しから補助視点を選択。極端な真上の俯角へ逃げない | 旧市街6地点・渓谷3地点をPC/タッチで描画 |
| 切替だけで押し続けた移動を曲げない | スティック/キー入力開始時の方向基準を保持。方向の変更はその基準で反映し、ニュートラル後に新しい画面へ合わせる | 実キー/実タッチの連続走行、全方向の単体試験、PC/タッチの到達点一致 |
| 小さな遮蔽物のたびに戻さない | 区間の向きを保持。復帰には見通しの連続回復1.2秒、滞在2.5秒、最後の遮蔽から5mを必要にする | 境界の単体試験、出入口を8回交互に動く実入力試験 |
| 狭い出入口で視点を往復させない | 中央建物の西廊下は実際の中心線X=-12にカメラを置く区間として扱い、入口から廊下まで同じ側を維持 | 西ドア進入→廊下で方向変更→ジャンプ→退出、続けて境界反復 |
| ジャンプ・鉄棒等の途中で旋回しない | 空中・パルクール中はカメラの方角を保持。距離/高さは遮蔽回避に使う | 全連続空中サンプルで方角差ゼロ、ネイティブ動作の入力回帰 |
| 壁の中を通る補間を描かない | カメラ体積を10cm間隔で検査。見通せる直前位置を一時保持し、接続できない狭い箇所だけカットする | 全移動サンプルでカメラ安全・足元可視を確認 |

`hybrid-camera.js` は視点の選択と区間の保持、`fixed-camera-trial.js` は入力基準と地形問い合わせ、`human-view.js` は描画への反映を担う。ミニマップは実際のカメラの方角へ合わせる。かんたん操作の設定画面・ホーム・遊び方に試作専用の説明を表示する。

追加の家の遮蔽判定では、空洞の家を一個の中身の詰まった箱として扱わず、実際の壁と屋根・上部の化粧面を分ける。プレイヤーの衝突・移動物理・ナビ・自動射撃・ランキング規則は変更しない。従来の `cameraTrial=fixed` と通常のPCマウス操作は引き続き利用できる。

## 対象と動作証拠

- 比較画面の先頭は北側上階通路 `[-10.5,4.0001,-11.6]`。屋根上の箱と左の橙色階段を照合し、屋根越しに人物だけが見える症状を再現した地点。最後の写真の正確な撮影座標は未確定。
- 前の写真3地点（梁・傾斜屋根・柱前の地上）は既存の同じ座標で検証。通路・空洞の家も含め旧市街6地点、渓谷の下/中/上の3地点を、PC/タッチ計18場面で保存。
- 北側上階通路の走行と反転ジャンプ、西ドアの進入・方向変更・ジャンプ・退出を、テレポートせずに実キー/実タッチで実施。タッチのジャンプは左指を保持して二本目の指で操作する。
- 各ルートの到達点はPC/タッチで一致。北側の押し続けた横移動は、カメラの向きが変わっても同じ直線を保つ。ジャンプ中の地形接触による5cmの位置補正は、カメラによる方向変化と区別する。
- 境界反復を含む計1654移動フレームで、安全なカメラ位置・頭と足元の可視・WebGLエラー0。北通路と西ドアの往復は各2回以内のカット。境界を8回交互に動いた区間では追加カット1回、区間の再選択0回。
- `bench/hybrid-camera.test.cjs`：キー/タッチの方向保持・意図的な方向変更・ニュートラルでの更新・技の終了方向・リセット・境界の往復抑止・空中の方角保持。
- 生結果と画像は `browser-evidence/hybrid-camera/`。比較用のプレイ記録は送信しない。
- CIのソフトウェアGPUへ連続描画を積みすぎないよう、移動・入力・カメラ判定は60Hz、走行中の描画は10Hzで検証する。撮影待ちは90秒。ゲーム本体の描画頻度は変更しない。カメラの試験は既存のfoundation試験から独立したCIジョブで実行する。
- 比較ページは両表示・地点選択・実キーによる移動・PC/タッチ幅・外部POST 0を確認。
- 回帰確認：`follow-camera.test.cjs`、`human-view-running.test.cjs`、`minimap.test.cjs`、`start-readiness.test.cjs`、`roof-clearance.test.cjs`、`tower-tunnel.test.cjs`。ブラウザでは `opaque-walls-browser.cjs` の従来表示と全衝突/ナビ一致、`human-running-browser.cjs` の両マップ/PC・タッチの既存動作、`start-readiness-browser.cjs` の冷間読込・通常開始・入門・メニュー・再挑戦・読込失敗からの回復を確認。
- `minimap-browser.cjs` の両マップ×4画面配置、`easy-controls-browser.cjs` の通常の移動・二本指の見回し・解除・手動視点復帰・日英の操作選択も通過。

## 限界

狭い通路でカメラを回り込ませる空間がない場合はカットが残る。すべての地形・全パルクール経路を網羅した検証ではない。実機iPhoneでの操作感・FPS、初見プレイヤーが迷わず進めるかは未確認。ヘッドレスブラウザのタッチ入力確認を実機確認として扱わない。

容量17.51MB：20MB目安の88%、50MB上限の35%。公開時はCI、意図したSHAのPagesデプロイ、公開ファイルのバイト一致、両マップと比較ページの実動作を別々に確認する。公開検証の生結果は `browser-evidence/hybrid-camera/` に保存する。
