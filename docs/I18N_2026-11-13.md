# 多言語対応（2026-11-13）

ナイトラインと同じ並び：Auto / 日本語 / English / ไทย / Tiếng Việt / Português (Brasil) / Türkçe / Español。

## しくみ
- 画面の文言は日本語のままコードに書いてあり、`i18n.js` が表示時に辞書で置き換える（日本語が正）。
- 辞書：`i18n-en.js`（英語・既存）＋`i18n-en-extra.js`（英語の追加分）＋言語パック `i18n-{th,vi,pt,tr,es}.js`。パックは選んだ言語の1つだけ読み込む。
- パックは生成物。直接編集しない。元は `tools/i18n/src/<言語>.NN.txt`（`<id> <訳>`）。id は `tools/i18n/keys.tsv`（追記のみ・番号は変えない）。
- 言語の決め方：`?lang=auto|ja|en|th|vi|pt|tr|es` → 保存値 `localStorage sky.lang` → ブラウザの言語（navigator.languages）→ 英語。旧値 `en`/`ja` もそのまま使える。
- 言語セレクトは `#langToggle`（ホームの上のボタン列）。変えるとその言語で再読み込みする。

## 文言を足す・直すとき
1. コードに日本語を書く（英語を別に用意する場合は `i18n-en.js` か `tools/i18n/extra-src.tsv` に `日本語<TAB>English`）。
2. `node tools/i18n/keys.cjs` で id を採番（末尾に足される）。
3. 5言語の訳を `tools/i18n/src/<言語>.NN.txt` に新しいファイルとして足す。
4. `node tools/i18n/build_packs.cjs`、`node bench/i18n-packs.test.cjs`、`node bench/i18n-browser.cjs`。
- 数字・単位・キー名・記号を保つ、`$1` などの置き換え記号の数が元の括弧数以下、は単体テストが確かめる。

## 検査
- `bench/i18n-packs.test.cjs`：全文言に訳がある／日本語が残らない／数字とキー名が保たれる／括弧が揃う。
- `bench/i18n-browser.cjs`：Auto判定・選択の保存・両マップのホームとプレイ中・連続入門コースで、英語より多く日本語が残らないこと。
- CI：`.github/workflows/i18n.yml`。

## 既知の残り
- 英語でも日本語のまま残る文言（「自由調整」パネル、開発用パネル、練習場パネルの一部。ホームで約86、渓谷で約88、入門コースで約99）は、全言語でも日本語のまま。
- 訳はネイティブ確認前。特にタイ語・ベトナム語・トルコ語は、公開後の指摘で直す前提。
- 長い訳（タイ語・ポルトガル語）でホームの上のボタン列が幅に収まらないときは2行目に折り返す（667×375 で確認）。
