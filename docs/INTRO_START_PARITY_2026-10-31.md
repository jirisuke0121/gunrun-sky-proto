# 入門の人物・銃・開始処理を本番と揃える（2026-10-31）

公開版7a60116に対し、iPhoneの入門画面が三人称にならず、簡易的な銃を表示するとの指摘へ対応する。

原因は、ホーム先頭の入門ボタンだけが人物・武器の読み込みを待たず、`game.br()`を直接呼んでいたこと。本番ボタンに登録された開始前の確認・音声等のリスナーも通っていなかった。

入門ボタンはHTMLの初期状態から無効にし、Unity人物・HGの詳細モデル・通常開始ボタンの準備が揃ってから有効化する。準備後は通常開始ボタンのクリック経路を使い、入門フラグはその同期呼び出しだけに限定する。モデルの読み込み失敗時も、違う表示で開始せず再読み込みを案内する。既存のVキー視点切替や通常モードの設定は変更しない。

## 手動確認

ローカルの確認サーバーで、enhancementsモジュール、人物GLB、HGのGLBを意図的に止めて比較した。外部への記録送信は検証フラグとローカル接続で除外した。

- 修正前の旧市街：人物未読込・武器拡張未起動・HG未読込なのに入門がplayへ遷移し、ライフ∞になることを再現。
- 修正後の両マップ：同じ読み込み待ちで入門は無効、押してもmenuを維持。読み込みを進めると開始可能になる。
- 読み込み後の両マップ：入門がUnityアニメーションの三人称で開始することを確認。渓谷では詳細HG `Meshy HG mobile LOD` が人物の保持武器として表示され、音声グラフrunning・ライフ∞を確認。
- 渓谷で入門からホームへ戻り、通常ノーマルを開始。三人称・同じHG・ライフ5で開始し、入門フラグが残らないことを確認。

これはMacブラウザーで読み込みを制御した確認であり、報告元のiPhone実機での再確認は未実施。自動テストの新規追加・ローカル実行は行わず、構文・差分空白と既存CIで確認する。公開の最終状態はPR・Pages・実配信で別途確認する。
