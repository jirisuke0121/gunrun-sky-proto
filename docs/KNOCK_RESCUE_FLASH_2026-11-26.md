# 撃ち落とし・救済・閃光玉の見直し（2026-11-26）

紹介動画（逃走劇版）を撮って見つかった3つ。動画の撮り方ではなく、ゲームの仕様側の問題だった。
ランキングの版は `corridor-balanced-score-v15` のまま（Worker を更新できる環境がなかった。下の「版」）。

## 1. 撃ち落とし（`zombie-fall.js` の `EDGE`）

**問題**：「高台はゾンビを撃ち落とせる」が核なのに、高台から撃っても落ちない。
- HGの1発で押されるのは約1.9 m（`knock` 7.8 m/s、押す向きは弾の向き）。縁から1.5 m以内で当たったときしか落ちない。
- 実際に当たるのは、屋上に上がりきって縁から離れたゾンビがほとんど（中央屋上などは階段・坂で上がれる）。

**直したこと**：当たったゾンビの押される向き2.6 m以内に、1.5 m以上の段差の縁があり、間に壁がなければ、縁を0.5 m越えるところまで押しを強める（最大で元の2倍）。縁が近くにないときは何も変えない。

**測り方**：`node tools/high-ground-knockoff.cjs --secs=20`（4 m以上の足場54か所に立ち止まり、自動射撃・無敵・弾は無限、ふつうの出現で20秒。乱数固定）。

| ふつう・54か所・各20秒 | 前 | 後 |
|---|---|---|
| 当たった数 | 612 | 594 |
| 当たって1.5 m以上落ちた | 35（5.7%） | 50（8.4%） |
| 落下で倒した | 26 | 30 |
| 銃で倒した | 41 | 43 |

- 東の高台（y 12）の3か所：落ちた 0 → 5。
- 全体で大きく増えないのは、当たる場所の多くが「縁から2.6 m より奥」だから。広い屋上が階段・坂でつながっている地形のまま。これ以上は地形の判断（登り口を縁にする・階段を減らす）になるので、ここでは変えていない。
- `knocked`（当たったあとに一度でも浮いた数）は、被弾で毎回少し跳ねるので当たった数より多い。落ちた数は「1.5 m以上」で数える。

## 2. 救済（`free-hook.js`）

**問題**：追い詰められた場面で、救済の行き先がほとんど見つからない。
- 低い場所151か所で、6体に本物の追跡で囲ませ、3体が5 m以内に来た瞬間に救済の行き先を探させた（`tools/rescue-trapped.cjs`）。**83%で行き先なし**。
- 原因：飛ぶ線全体が「どのゾンビからも3 m以上」の条件だった。線は自分の足元から始まるので、**3 m以内にゾンビが1体いるだけで全部の足場が外れていた**。いちばん救済が要る場面で必ず出ない作り。

**直したこと**：
1. 線の最初の2.5 mは判定に入れない（`startFree`）。
2. 線がゾンビの足元から2.4 m以上の高さを通るなら塞がない（`reachUp`）。線の高さは出発から足場へ直線で上がるとみなす。
3. 壁で止まる足場を飛ばして試す数を 24 → 48（`tries`）。
4. それでも無いときは、条件を一段ゆるめてもう一度探す（足場の周りのゾンビ 4.5 → 3 m、線 3 → 2 m、足場の端も可）。

| 追い詰められた瞬間（151か所） | 前 | 1だけ | 1〜3 | 1〜4 |
|---|---|---|---|---|
| 行き先なし | 83% | 60% | 52% | **25%** |

- 残り25%（38か所）の多くは、まっすぐ引くと壁・天井に当たる狭い路地（29か所）。フックの引き方（まっすぐ）のままでは無理。

## 3. 閃光玉（`flashbang.js`）

**問題**：投げた直後に画面全体が0.8秒ほぼ白（0.84）になり、群れが止まる瞬間が見えない。止まったゾンビごとに「停止 3.2秒」の札が出て、群れだと画面がうるさい。

**直したこと**：白は 0.5 から 0.5秒で消える（減光の設定は前のまま 0.22・0.4秒）。札の文字はやめ、残り時間の黄色い棒と星だけ残す。何体止めたかは1行の通知「閃光！ N体が4秒停止」で出る。

## 版（ランキング）

1と2は順位対象の難易度の挙動を変える（落とせる・逃げられる場面が増える＝前より少し生き残りやすい）。AGENTS.md の決まりでは版を上げる変更だが、版を上げるには Worker を先に更新する必要があり、この環境には Cloudflare の資格情報がなかった。版を上げないまま公開した。上げるなら `ranked-rules.js` の `version` を v16 にし、`server/` で `npx wrangler deploy` → `GET /` の `rankedRules` 確認 → Pages の順。
