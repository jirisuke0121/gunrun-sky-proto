# 意味のある物を足す（旧市街、2026-11-22）

`map-links.js`（新規。`?links=0` で足す前のマップ）。前後は `docs/map-links-2026-11-22.jpg`（左が前、右が後）。
ランキングの版は上げていない（`corridor-balanced-score-v15` のまま。本人の指示）。

## 基準

撤去（`docs/MAP_NOISE_2026-11-22.md`）と同じ。**その物があることで、次の行動が広がるか。**
足す物は「上に乗ると、床からは届かない足場に届く」ことを条件にした。

## 調べ方

1. 当たり判定の箱1,097個を0.5 mの格子に落とし、立てる高さの地図を作る。
2. 高さの差0.2 m以内でつながる面を「台」としてまとめる（422個。6㎡以上の高い台は約60個）。
3. 台どうしを、走りジャンプ・よじ登り・飛び降りで結ぶ。高所のまま行ける先の数を、台ごとに出す。
4. 中央屋上（8 m、641㎡）のまわりで「床から届かないのに近い、高い足場」を探す。

結果：中央屋上から高所のまま行ける先は8つあるが、**床から届かない近くの足場は、東の塔の上（12 m）だけ**（隙間3 m・上り4 m）。
塔の上へは、東の長い斜面を13 m登って段を上がる道しかなかった。西・南・北は、縁から届く先がすでにある（櫓・ロープ・ジップ・階段・踏み切り台）。

## 足した物：石段3つ（中央屋上の北東）

| 物 | 範囲（x、z） | 天面 | 床から | 役割 |
|---|---|---|---|---|
| 石段1 | 3.6〜5.8、−4.2〜−2 | 10.0 m | 2.0 m | 北の箱（10 m）から2.8 m跳ぶ。床からもよじ登れる |
| 石段2 | 7.8〜10、−4.2〜−2 | 11.0 m | 3.0 m | 石段1から2 m跳ぶ。床からは、縁の1 m以上手前で跳ぶとつかめる |

- つながり：**北の箱 → 石段1 → 石段2 → 石段3 → 東の塔の上 → ジップ・東塔（14.4 m）・東の屋根**。逆向きも通れる。
- 石段の間は2 m空いている。屋上の床を南北に走る人は、間を通り抜けられる。
- 北の箱は、11/22の撤去で「開始位置を守るために残した、登るだけの箱」だった。これで高い道の入口になる。

- 見た目は北の箱と同じ（漆喰と木組み、天面は敷石）。新しい色は足していない。

## 戻した物：柵2本（11/22の撤去の直し）

撤去で柵8本を全部外したが、**開始位置の基準を割っていた**（`docs/START_SPOTS_2026-11-05.md`：最初の追手が触れるまで、全試行4.5〜12秒・中央値5秒以上）。
撤去のときは各3回しか測っておらず、見逃した。乱数を固定して16通りで測り直した（止まった無敵のプレイヤー、ハード）：

| マップの状態 | north-roof 最短 / 中央値 | north-mid 最短 / 中央値 |
|---|---|---|
| 撤去の前 | 5.2 / 6.4 秒 | 5.5 / 6.5 秒 |
| 撤去の後（柵8本なし） | **4.2**（16回中1回が基準割れ）/ 6.0 秒 | 4.5 / 5.5 秒 |
| 柵 `west-north` だけ残す | 5.5 / 6.5 秒 | 4.5 / 5.5 秒 |
| 柵 `north-east` だけ残す | 4.2 / 6.0 秒 | 5.1 / 5.6 秒 |
| **柵2本を残す＋石段（今回）** | **5.1 / 6.4 秒** | **5.2 / 5.9 秒** |

- 効いていたのは2本だけ：`west-north`（西の縁の帯、z −2.5。north-roof へ北上してくる追手を遅らせる）と `north-east`（北の縁の帯、x 3.5。north-mid へ東へ来る追手を遅らせる）。
- この2本を `map-prune.js` の `KEEP_RAILS` で残した。ほかの6本は撤去のまま。撤去の合計は30個 → 28個。
- ノーマルは今回の状態で north-roof 5.6〜10秒、north-mid 5.5〜7秒。
- 石段は開始の時間を変えない（石段あり・なしで、同じ乱数の16回が同じ値）。
- 柵は「乗り越えるだけ」の物なので、基準（次の行動が広がるか）には合わない。北の箱と同じく、開始位置を守るための例外。外したい場合は、開始位置の基準の方を見直す必要がある（要判断）。

## 確かめたこと（実ゲームの物理）

`node bench/map-links-browser.cjs`（103項目）。

- **跳び移り**：8本のつながり（箱↔石段1↔石段2↔石段3↔塔）× 横の位置3か所 × 踏み切り3通り（縁の0.05 / 0.3 / 0.8 m手前）＝72本すべて、よじ登りなしで着地。ノーマル・ハード、物理の刻み 1/120・1/60 秒で同じ。
- **床から**：石段1は登れる。石段2は縁の1 m以上手前で跳ぶと縁をつかめる（0.3 m手前では届かない）。石段3は、0.3〜2.8 m手前のどこで跳んでも登れない。

## 実測で分かったこと（次に物を足すときの数字）

- **人がよじ登れる高さは約3.2 mまで**（3.2 mは縁の1.9〜3.2 m手前で跳ぶとつかめる。3.3 mはつかめない）。`docs/MAP_REVIEW_2026-11-11.md` の「約2.8 m」は、縁の近くで跳んだ場合の値だった。高さ3.0 mは、縁の1.1 m以上手前で跳べばつかめる。
- 物理は描画の速さによらない（1/120・1/60・1/30 秒の刻みで、同じ跳び移りの結果になった）。
- **追手が登れる高さは3.6 mまで**（経路の網の決まり）。追手が登るには、床の高さに当たり判定のある物が要る。下が空いた薄い足場には、足場の外から直接は登れない。
- **人の当たり判定は四角**。細い柱（0.12〜0.22 m）でも、柱の中心から±0.2 m以内を走ると、よけずにその場で止まる。

## 試して入れなかった形

- **柱で支えた木の足場（高さ3.2 m、下は空いている）**：床を走る人のじゃまにならない案。
  - 柱に当たり判定を付けると、柱の線の上を走った人が止まる（既存の検査 `roof-trenches` の「南北の溝を西へ」が、柱で止まって失敗した）。
  - 柱を見た目だけにすると、追手は北の箱からの跳び移りでしか来られない。足場の上で止まって自動で撃つだけで、ノーマル3回中3回・ハード3回中2回、無傷で2分生き残れた。入れない。
- **石段1を2.6 mにする**：同じ検査で、ノーマル6回中3回が2分生き残った（北を箱、西を溝に守られる位置のため）。2.0 mに下げた。
- **北のバルコニー（4 m）に木の台を置いて、屋上へ上がれるようにする**：窓破りダイブ → 屋内の北の通路 → バルコニー → 屋上 → 石段 → 塔、と1本につながる案。
  人は2回のよじ登りで屋上へ上がれるが、追手は台に登れない（バルコニーの床の下に地面があり、経路の網が「降りる」と解釈する）。追手は14〜19秒かかる回り道になり、人だけの近道になる。入れない。
- **溝をまたぐ細い梁**（11/22の候補2）：追手は溝を降りて登り直す（約3秒）。梁があると追手も歩いて渡れて、溝の意味がなくなる。入れない。
- **屋上の東の縁に箱1つ**（11/22の候補1）：石段3がその役目。箱1つだと北の箱からは届かないので、3つの段にした。

## 足さなかった場所と理由

- **中央屋上の南東・南西・北西**：縁から届く先がすでにあり、床から届かない近くの足場がない。箱を置いても「登れるが、上から届く先が屋上と同じ」＝撤去した物と同じになる。
- **西の街区**：高い台どうしがすでに細かくつながっている（高所のまま行ける先が10以上の台が多い）。
- 高所の出口が少ない台（調べ方3で、行ける先が0〜1）：北の5 mの壁の上（x 23〜36、z −27〜−25）、北西の角の屋根（4.4 m）、東端デッキ（3.6 m）、北の通りの3.4 mの台2つ。
  どれも、近くに行き先になる高い足場がない（新しい足場の列を建てる＝マップを広げることになる）。今回は触っていない。
