# マップの磨き：世界観の残りの色と、走りの引っかかりの実測（旧市街、2026-11-22）

11/21〜22 の改装（遠景・壁の塗り・世界観・ノイズ撤去・石段）のあとの状態を、2つの観点で見直した。
前後は `docs/map-polish-2026-11-22.jpg`（左が前、右が後）。当たり判定・ルート・描画回数・三角形は変えていない。

## 1. 世界観：決まりから外れた色が2種類残っていた

決まり（`docs/WORLD_CONCEPT_2026-11-22.md`）は「石／漆喰と木組み／木／スレート／黄・橙は目印だけ」。
固定8視点（`bench/eye-views.cjs`）と地区ごとの広い視点で描画し、外れて見える面を1つずつ当たり判定の箱までたどった。

| 見えていた物 | 正体 | 直し |
|---|---|---|
| 北東の青緑の石の塊・階段、南の桃色の敷石と階段、西の橙がかった床 | 10月の「地区ごとの色ずらし」（`districtTint`）。世界観を決める前の仕組みで、漆喰・木・スレートに塗られていない面（＝石と敷石）にだけ残っていた。東は赤を0.6倍・北は青を0.58倍にしていた | ずらす量を3割にした（`DISTRICT_SHIFT`）。石は1つの素材で、地区の違いは暖かい／冷たいの少しの差になる |
| 西の赤茶の倉庫の壁（高さ4.6 m、5個） | マップデータの色 `0xb5604a`・`0x8f4a3a` | 漆喰と木組み（ほかの家と同じ。となりの建物と違う色を選ぶ）。天面は明るい石 |
| 西の緑・赤・紺の積み荷（13個）、赤い板壁2枚とひさし1枚 | マップデータの色 `0x5f9c6c`・`0xc2624e`・`0x5b88c2`、薄い `0xb5604a`・`0x8f4a3a` | 木。積み荷は高さの段（2.7 / 4.0 / 4.4 m）を色で分けていたので、明るい木・中間・暗い木の3色にして段の違いは残した |

- 黄色の木箱（各積み荷の1段目、1.3 m）は黄色のまま。黄は目印色で、「ここから登る」の合図になっている。
- 東端デッキの赤い板の柵は、まとめられていない単独のメッシュだったので、色だけ木にした（板の模様は付かない）。
- 既存の建物の色は変わらない（色つきの箱は、建物のまとまりの計算に入れていない）。
- `?walls=plain` で、どれも前の色に戻る（これまでの切り替えと同じ）。

### 直していない色（判断したもの）

| 物 | 理由 |
|---|---|
| スレートの屋根が朝焼けでかなり青く見える | スレートは決まりの中の素材。暖色の壁との対比で「屋根＝走れる面」が読める。彩度を下げるかは実機の見え方で決める |
| 西の赤いひさし（当たり判定なしの飾り） | 赤は仕掛け（樽・ジャンプ台）にも使っている色。飾りを消す・塗り替えるのは別の判断（要判断） |
| 黄色の高い柱（西の北、高さ5.4〜6.8 m、4本） | 柱ではなく、西の屋根の黄色い木箱の積み重ね（`town-heights.js` の `crates`。1.2 m・2.4 mの足がかり）。意図して置いた物なので残す |
| 緑の細い枠（屋内の入口） | 入口の合図。細い |
| 溝の底の灰青の板 | 石・スレートの範囲 |

## 2. 快適さ：走っていて止められる所を実測した

「物を置く基準」（その物で次の行動が広がるか）で28個を撤去したあとに、**まだ走りを止めるだけの物が残っていないか**を、目ではなく実ゲームの物理で数えた。

- 方法（`tools/run-snags.cjs` と `tools/run-snags.py`）：追手の経路の足場点 4,132 すべてから、8方向へ跳ばずに0.8秒走らせる（何もなければ4.7 m進む）。止まった所について、前にある箱を調べて仕分ける。
- 結果（32,084本）：

| 結果 | 本数 | 割合 |
|---|---|---|
| 止められずに走れた（2.8 m以上） | 21,929 | 68.3% |
| 縁で止まった（歩いては降りられない。意図どおり） | 6,102 | 19.0% |
| 壁に当たった | 3,079 | 9.6% |
| 段差・斜面で高さが変わった | 742 | 2.3% |
| **小さい物に止められた**（腰より低い物、または幅0.8 m以下で向こうに床が続く物） | **232** | **0.7%**（47個の物） |

- 47個を多い順に1つずつ確かめた。**走りを止めるだけの物は見つからなかった。** 内訳：
  - 薄い壁の端に斜めに当たったもの（西の小屋の壁 `x −52.4`・`x −60` など）：壁。
  - 2段重ねの木箱3組（東の通り `x 39.6, z 0`、西 `x −51.4, z 2`、北西 `x −45`）：すぐ横の3〜4.4 mの台へ上がる足がかり（11/22 の撤去で残した物）。
  - 低い手すり（北のバルコニー・東の通り `x 17`・北の通り `z −17`）：向こうは落下か水路。落下を防ぐ。
  - 中央屋上の柵2本：開始位置を守るために残した物（`docs/MAP_LINKS_2026-11-22.md`）。
  - 階段の側面、屋根の縁の段。
- 入口の緑の細い枠（幅0.1 m）に止められたのは 32,084 本中2本。直さない。
- つまり、**走る線の上の引っかかりは、今の地形では問題になっていない**。この先に物を足したら、同じ検査で前後を比べられる。

### 跳んでいる途中の引っかかり（`tools/jump-snags.cjs`、同日追記）

足場点の半分（2,066点）から8方向へ、0.35秒走ってから跳び、前へ押したまま1.2秒進める。空中で横の速さが半分未満に落ちた所を数えた。
壁に向かって跳んだだけの回を外すため、「跳ばずに走ったときは止まらなかった点・向き」（8,728通り）だけを数えている。縁をつかむ・はしご・壁走りなどの技に移った回も外した。

| 結果 | 数 | 割合 |
|---|---|---|
| 跳んでも止められなかった | 7,790 | 89.3% |
| 空中で当たった | 938 | 10.7% |
| 　うち、跳んだ先にあった壁・箱 | 685 | |
| 　うち、段差・斜面 | 76 | |
| 　うち、頭の高さの物（床から0.9 m以上上に下面がある） | 177 | 2.0% |

- 壁・箱は、跳べば走るより遠くまで進む（約9 m）ので、その先の壁に当たっただけ。引っかかりではない。
- **頭の高さの物177件**を、床からの空き（物の下面の高さ）で分けた：

| 空き | 件数 | 正体 |
|---|---|---|
| 1.0〜1.5 m | 59 | 2段重ねの木箱の上の段（東の通り・西）、屋根の縁の出っ張り。上の段への足がかりで、壁と同じ |
| 2.0〜2.2 m | 30 | 低い梁・手すりの上の桁 |
| 2.4〜2.6 m | 58 | **中央ブロックの出入口・窓の上の横木**（高さ2.5 m）。出入口の中で跳ぶと、頭が横木の面に当たって横の速さが0になる |
| 2.8〜3.0 m | 26 | 同上（少し高い所） |

- 結論：**屋外の走りと跳び移りの途中に、何もなくて止まる所はなかった。** 頭が当たるのは、高さ2.5 mの出入口の中で跳んだときだけ（東西南北の4か所×上下の階）。
- 出入口の中で跳ぶ場面は少なく、物理（ランキングに関わる）を変えてまで直す理由はないと判断して、**何も変えていない**。気になるなら次の2案がある：①横木を2.8 mにする（走って通れる高さは変わらず、跳んでも当たらない。ただし出入口の見た目が変わる）、②頭の当たりを「止まる」でなく「頭を打って落ちる」にする（物理の変更。ランキングの版が絡む）。要判断。
- 試運転（52点）では当たった割合が22%と出た。壁に向かって跳んだ回と、縁をつかんだ回（技への移行）を数えていたため。今の数字は、それらを外した後。
