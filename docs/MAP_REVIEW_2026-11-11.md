# 旧市街マップの見直し（2026-11-11）

足場グラフ（NAV 4148点）と実ゲームの物理（ジャンプ439回・登り85回のボット走行）で旧市街を診断し、弱い所を3か所直した。マップは広げていない。

## 診断（変更前）

- 高台の面積の86%は、高台のまま行ける先が2つ以上ある。全体の繋がりは良い。
- 弱い所:
  - A 中央屋上: 約600㎡が1枚の平らな床（高台の平らな面の34%）。走るだけの直線が最長27 m。
  - B 西→中央: フックなしで高所のまま中央へ戻る道が、西の櫓（7 m）経由の1本だけ。東→西はジップ・鉄棒2本・塔のトンネルがある。
  - C 東端デッキ（3.6 m）: 出口が、来た長い階段（約11 m登り返す）と行き止まりの段だけ。
  - D 北西の角の屋根（35㎡）: 出口が1つ（未対応）。
- 実測した人間の動き: 走りジャンプは足場の点どうしで約5.7 mまで、よじ登りは約2.8 mまで。
  `tools/escape-graph.cjs` は 4.3 m・2.0 m で計算しているので、「詰み」の点数は多めに出ている可能性がある（未修正）。
- 通りから1回のよじ登りで2.5 m以上の台に乗れる所が34か所（西19・東9・中央ほか6）。方針（下から登れる所は最小限）との兼ね合いは未決。

## 残り2件の判断（地形は変えていない）

### 通りから登れる34か所（足場のまとまりで26か所）

- 16か所は、すぐ横に低い段（0.9〜2.1 m）がある。設計どおりの積み荷の段（1.3 / 2.7 / 4.0 m など）で、1段目を飛ばして登れるだけ。登り口の数は増えていない。
- 10か所は横に低い段がない。乗る先は次の4つ。
  - 西の2.6 mの台（x -42〜-36.5、z -12〜-5）と東の2.6 mの屋根（x 34〜38.5、z 7〜11.5）: どちらも、高所のまま行ける先が0。屋上の網への近道にならない。
  - 南西の2.8 mの台（x -32〜-25、z 12〜18）: 設計どおりの段の一部。
  - 西の2.7 mの梁（x -43.4〜-42.8）: 幅0.6 mの梁。
- 結論: 想定外の近道（通りから屋上の網へ2動作で入れる新しい登り口）は見つからなかった。変更なし。
- 残る事実: 人間の登れる高さは実測で約2.8 m。設計時の想定（2 m）より高いので、今後2.1〜2.8 mの台を新しく置くと、通りから直接登れる。

### D 北西の角の屋根（4.4 m、35㎡）

- 出口は、南の飛び石の柱（4.3 m）→ 北西のデッキ（4.2 m）の1本。まわりは通り（0 m）と水路（-3.5 m）で、どこからでも飛び降りられる（ダメージなし）。
- 次に近い高台は10 m以上先。2本目の高所の出口を作るには、何もない所に足場の列を新しく建てる必要がある。飛び石をもう1本並べても、行き先は同じデッキになる。
- 結論: 変更なし。北西のデッキの先には窓破りダイブの踏み切り台ができたので、角の屋根 → 飛び石 → デッキ → 階段の上 → 踏み切り台 → 窓、と1本の流れにはなった。
