# 初回案内・ニックネーム・入門への誘導（2026-11-02）

NIGHTLINEの入口（初回判定・名前の入力規則・初回だけの操作ガイド）を空中回廊に流用。得点・ルール・記録の条件は変更しない。

## 初回の流れ

- 初回だけ、ホームの上に案内画面（`onboarding.js` / `onboarding.css`）を表示。内容は目的（2分・30秒ごとボーナス）、操作4項目（PCはキー、スマホはタッチの文言に自動で切替）、ニックネーム入力（任意）。
- 「入門モードで始める（ライフ無限）」を主ボタンにし、押すと既存の入門ボタンを押して入門を始める（読み込み前は「読み込み中…」で待つ）。「本番へ進む」はホームへ。「操作設定を開く」は既存の設定（☰メニュー）を開く。
- 初回判定：`gunrun-onboarding-v1` が未保存で、送信済みの本番記録（`gunrun-run-history-v1`）が1件もなく、開発モードでないとき。案内を出した時点で保存し、2回目以降は出さない。既存プレイヤーには出ない。
- ホーム右上の「遊び方」から、いつでも同じ画面を開ける（ニックネームの変更もここ）。
- 自動テストのブラウザ（`navigator.webdriver`）には既定で出さない。`?onboarding=1` で強制表示、`?onboarding=reset` で保存を消して表示、`?onboarding=auto` は自動ブラウザでも通常の初回判定を適用。

## ニックネーム

- 規則はNIGHTLINEと同じ：2〜14文字の文字・数字・`_`・`-`、全角は半角に正規化、英字は大文字（`player-name.js`、クライアントとWorkerで共通）。空欄でも遊べる。
- 端末の `gunrun-name` に保存し、記録の送信時に `name` として付ける。名前を設定していない端末は送らない。
- Workerは受信時に同じ規則で検査し、通らない名前は捨てる。ランキングとゴースト表示では、読み出し時にも再検査して通ったものだけ表示（古いWorkerで保存された値の対策）。名前がなければ従来どおり端末IDの先頭4文字。
- 本人の行は従来どおり「あなた」。名前は他プレイヤーの行に出る。

## 公開時の手順

名前をランキングに出すにはWorkerの更新が必要（`server/worker.js`）。D1のテーブル変更はない。Workerを更新するまでは、案内画面・名前の保存・送信まで動き、ランキングは従来の表示のまま。ゲームとWorkerはどちらを先に更新しても動く。

## 確認

- `bench/onboarding.test.cjs`：名前規則、記録に保存済みの名前だけが付くこと。`bench/shared-score.test.cjs`：有効な名前の表示、無効な名前の破棄、名前なしの匿名維持。`bench/ranked-ghost.test.cjs`：ゴースト応答の項目。
- `bench/onboarding-browser.cjs`（両マップ）：自動ブラウザでは出ない、初回は出る、不正な名前は保存されず画面が残る、正しい名前で入門が始まる、再読み込みでは出ない、遊び方で再表示して記録が変わらない、送信済み記録がある端末では出ない、本番へ進むでは何も始まらない、スマホ横・英語で収まる。外部POSTは0。
- 人間の初見プレイ、実機スマホ、動画つきの案内は未確認・未実装。
