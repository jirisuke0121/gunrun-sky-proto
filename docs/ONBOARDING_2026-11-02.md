# 初回の流れ（NIGHTLINEの「初回走行」に合わせた作り）（2026-11-02）

NIGHTLINE最新版（10/31）の初回走行の流れを空中回廊に流用。得点・ルール・記録の条件は変更しない。

## 流れ

1. **初回判定**（`onboarding.js`）：以前に遊んだ痕跡（案内の記録・名前・送信済み記録・送信待ち・ゴースト2種・難易度/追従カメラ/画質の保存）が1つもなく、開発モード・特殊URL（練習・旧市街の鉄棒・リプレイ等）でないとき。通信は待たない。
2. **ホームを出さずにスタートカード**：タイトル、「ライフ無限の入門で、操作を試そう。」、操作2つ（移動・ジャンプ。スマホは左右ドラッグとボタン）、「入門は記録・ランキングに反映されません。」、ボタンは「タップしてスタート」の1つ。入門の準備ができるまでは「読み込み中…」。押した時点で初回の記録を保存し、入門モードを始める。名前入力・スキップ・設定リンクは出さない。
3. **入門中のコーチ**：画面上部に場面ごとの1行（0〜10秒：移動・ジャンプ、〜20秒：視点、〜40秒：壁・縁・はしご・フック、〜55秒：銃は自動・閃光弾）。55秒以降と一時停止中は出さない。PC/スマホで文言を切り替え。
4. **入門のあと（結果から次を案内）**：結果画面が、その走りの結果で次のおすすめを決める（`next-step.js`）。クリアまたは60秒以上生き残った → 「イージーで本番へ」を強調。60秒未満 → 「もう一度入門で」を強調し、落下なら「縁・壁へ跳ぶとつかんで越えられます」、追いつかれたなら「壁走り・フック・はしごで距離をとる」を表示。入門中の動作が重かった場合（既存の判定：5秒の準備後、1秒を10区間、45FPS未満が6区間）は、結果画面に「描画を軽くしますか？」を出し、答えるとホーム復帰時の同じ確認は出ない。そのあと名前の入力を1回だけ出す（約1.6秒後。「保存する」か「あとで」。名前を決めていなくても二度と自動では出さない）。
5. **それ以降**：ホームの「はじめての方へ／入門モードで試す」ブロックを非表示（既存プレイヤーも同様）。右上の「遊び方」から、操作4項目・名前の変更・「入門モードで練習する」・操作設定に入れる。

自動テストのブラウザ（`navigator.webdriver`）には既定で出さず、ホームの入門ブロックも残す（既存のbenchが押すため）。`?onboarding=1` で強制表示、`?onboarding=reset` で痕跡を消して表示、`?onboarding=auto` は自動ブラウザでも通常の初回判定。

NIGHTLINEにある完走後の報酬演出（レベルアップ・カラー選択権）は、対応する仕組みがないため入れていない。

## ニックネーム

- 規則はNIGHTLINEと同じ：2〜14文字の文字・数字・`_`・`-`、全角は半角に正規化、英字は大文字（`player-name.js`、クライアントとWorkerで共通）。空欄でも遊べる。
- 端末の `gunrun-name` に保存し、記録の送信時に `name` として付ける。Workerは受信時と読み出し時の両方で同じ規則で検査し、通ったものだけランキングとゴースト表示に出す。名前がなければ従来どおり端末IDの先頭4文字。本人の行は「あなた」。
- 名前をランキングに出すにはWorkerの更新が必要（D1のテーブル変更なし）。更新するまでは、保存・送信まで動き、ランキングは従来の表示。
