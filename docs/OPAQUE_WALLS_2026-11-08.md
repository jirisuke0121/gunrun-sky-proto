# 不透明な壁・足場の縁・人物の遮蔽輪郭（ローカル試作）

基点は `72c7b31`。塔のトンネル追加を取り込んだ作業ブランチ `codex/opaque-walls`。公開は未実施。

## 対象と完了条件

ユーザーが南壁の公開後に提示した3枚を、現行ゲームで照合してから変更した。

| 写真 | 対象 | 固定視点の比較位置 (x,y,z) |
|---|---|---|
| 1 | 西側から中央建物へ渡る細い梁 | -18.5, 7.3001, 1.4 |
| 2 | 西側の傾斜屋根の東端 | -34.3, 5.5001, 3.5 |
| 3 | 柱・土のう・箱の前の地上 | -26.5, .001, -1.5 |

- 壁全体を透かす表示を止め、壁の位置と高さを残す。
- 壁は落ち着いた灰色、水平面は明るい2mの敷石に分ける。既存の赤い屋根・色付き箱は保持する。
- 屋根と写真1の梁に明るい細い縁を足す。衝突のない手すりや足場を作らない。
- 人物のうち遮蔽物に隠れた部分だけ、水色の輪郭シルエットを描く。
- 衝突・移動・ナビを変えず、両マップとPC・タッチで描画・操作できる。

## 表示とカメラ

`surface-readability.js` を静的結合前に適用。壁の模様を抑え、歩行面を区別する。屋根と梁の縁は既存の外周上に1メッシュで描く。足元の当たり判定は元のまま。不透明表示では透過用の分割を不要にし、材質ごとの静的結合も有効にする。

固定視点は不透明を標準にする。まず同じ俯角で距離を短くし、地面が隠れたままなら俯角を深くする。方角・画面方向への移動は維持する。カメラ判定には見た目の屋根・軒の張り出しを含め、巨大な結合メッシュ全体のAABBは使わない。

写真1・2では元の俯角 -.65rad を維持。写真3では **-1.54rad（約88度）**まで見下ろす。**写真3の視点変化は大きい**。壁の透過をなくし足元中心の見通しを優先した試作であり、視点変化の操作感は実機での評価が必要。

屋内で天井が遮る場合は人物の輪郭を残す。`human-occlusion.js` は元の人物と形状・モーフ重みを共有し、GreaterDepthで実際に隠れた画素だけ描く。通常視点・一人称・非表示時に輪郭を残さない。

## 比較方法

`bench/opaque-walls-review.html` で変更前後と3地点を切り替え、「ここから遊ぶ」で操作する。比較用プレイは敵と記録送信を停止する。

- 変更前：`?camera=after&cameraTrial=fixed&wallView=classic&fixedOcclusion=fade`
- 変更後：`?camera=after&cameraTrial=fixed&wallView=opaque&fixedOcclusion=opaque`

`wallView=classic` は今回の材質・縁を戻す。前回の公開済み南壁の変更は保持する。

## 検証

- `opaque-walls-browser.cjs`：PC・タッチ × 変更前後、写真3地点と通路・屋内の計5地点。実際の足場上に配置し、全衝突ボックス・ナビ座標・辺数のハッシュが一致。地上の実キーD移動の到達点も一致。
- 不透明時の全サンプルで透過面0、カメラが衝突物・軒へ入らず、方角・ロールを維持。屋内では輪郭あり。写真3では隠れる足を含め輪郭あり。描画・シェーダーエラー0。
- 梁からPCのSpace・タッチのジャンプを実入力し、手動カメラへ戻すと輪郭が消えることを確認。渓谷でも起動・描画を確認。
- `human-running-browser.cjs`：両マップのPC・タッチで走行、旋回、射撃、装填、跳躍、縁つかみ、壁走り、視点切替が通過。
- `human-aim-browser.cjs`：両マップのPC・タッチで各23発。全武器・上下・走行・空中・スライド・自動照準、銃口/弾道/手の接点、一人称の回帰試験が通過。
- `fixed-input-browser.cjs`：両マップの横持ち・縦から横への切替、実タッチ8方向、方向変更、右視点操作の抑止、キャンセル、ジャンプ、手動視点復帰が通過。
- `human-view-running.test.cjs` / `follow-camera.test.cjs` / `roof-clearance.test.cjs` / `tower-tunnel.test.cjs` が通過。
- `start-readiness-browser.cjs`：両マップのPC・タッチで読込待ち、開始、メニュー、再挑戦、入門から通常への復帰が通過。銃モデル・演出音の404からの再読込復帰も通過。
- `wall-readability-browser.cjs`：前回の南壁について両マップ・両視点・変更前後の8組と、南階段の実入力歩行が通過。
- 比較ページの変更前後、3地点選択、実キーボード操作を確認。記録送信false。
- 容量17.50MB（20MB目安の87%、50MB上限の35%）。

画像・生結果は `browser-evidence/opaque-walls/`。実機スマホの操作感・FPS、初見プレイヤーの壁認識は未確認。ブラウザの描画確認は実機確認の代わりにはしない。
