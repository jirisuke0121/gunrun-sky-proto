# パラグライダー開幕（旧市街）2026-11-28

## 何を変えたか
旧市街の通常ラン（入門・イージー・ノーマル・ハード）の開幕を、「測定済みの高台10か所のどれかに立って始まる」から、
「飛行機で町の中央上空へ → パラグライダーで好きな場所へ降りる」に変えた（`paraglider-opening.js`）。

- **飛行機**：ランダムな方角から高さ46 mで飛んできて、約2.6秒で中央付近（中心 (0, -4) から ±6 m）の上空を通過し、そこで降ろす。降ろした後も4秒飛び続けて町の外へ去る。
- **パラグライダー**：降下は毎秒5.5 m、移動は最大毎秒12.5 m（11/28 夕方に9.5 → 12.5。下の「行ける範囲」）（画面の向き基準。PCはWASD、スマホはいつものスティック）。中央から全方向の端まで届く（下の測定）。
- **ジャンプで離脱**：パラグライダーを離し、横の速さはそのままで重力で落ちる。落下ダメージはない（ゲームにもともとない）。
- **飛行機から飛び降りる**（同日追加）：飛行機の上でジャンプ（スペース／ボタン）を押すと、その場所から滑空を始める。押さなければ中央の上空で自動で降ろす。早く飛び降りると町の外の上空から始まるので、町の上に入るまでは降ろす予定だった点（中央）へ向かう（離脱して落ちている間も毎秒12 m以上で向かう）。四角の範囲の制限は、町の中に一度入ってから効く。
- **ボタンの文字**：飛行機の上と滑空中は、ジャンプボタンを「飛び降りる」にする（`#tJump`、着地で元の文字に戻す。他の言語は `i18n.js` が置き換える）。PCの案内も「スペースで飛び降りる」。
- **町の端**：町は四角ではなく、雲海へ抜ける隙間がある。真下を毎秒30回調べ、地面がない所に出たら最後に地面があった点へ押し戻す（端が柔らかい壁になる）。それでも雲海まで落ちたら、一番近い足場に降ろす（`rescued`）。
- **着地で始まる**：地面に着くか、縁・はしご・壁走り・フックなどのパルクールの状態に入った瞬間が「着地」。それまでは
  - ランの時計 `z.t` が止まる（生存点・残り時間・追手の補充・群れ・武器箱の10秒の出現も止まる）。
  - ゾンビは地上に立って待つ（動きの絵だけ進む。考える処理は止まる）。
  - 着地すると、無敵1.5秒（従来の開始と同じ）、ゾンビは0.4秒後に追い始める。リプレイ（ゴースト）は着地から記録する。
- **リトライ**：ホームから始めたランだけ飛行機から。リトライ（もう一度・やり直し）は飛行機を飛ばして滑空から始まる。

## 開幕の武器箱（危険な場所ほど強い武器）
開幕に、待っているゾンビが多い場所ほど強い武器の箱を3つ置く（`rankDanger`、`weapon-drops.js` の `seedOpening`）。

- 危険度＝半径16 m以内のゾンビ1体ごとに `1 − 距離/16`（高さの差は1.5倍で数える）の合計。
- 一番危険な所にMG、次にSMG、その次にSG。箱どうしは14 m以上離し、ゾンビから4 m未満の所には置かない。
- 箱は最初から着地済みで、光の柱が空から見える。置き場所の候補は従来の武器箱と同じ（広い足場・頭上が空いている・行き来できる）。
- 着地までは、箱の消えるまでの時間（50秒）と10秒ごとの出現も止まる。上限5個は従来どおり（開幕3個＋その後の出現）。
- 得点の差：強い武器で撃破×30点・ダメージ×2点が伸びる。安全な所に降りて撃たずに逃げ切れば×1.3（パルクールクリア）が狙える。

## ゾンビの待ち位置
ランの準備は従来どおり測定済みの開始位置10か所（`start-spots.js`）の1つから行い（最初の群れの配置と武器箱の候補探し）、そのあと飛行機へ移す。
開始位置は毎回変わる（前回と同じ所は選ばない）ので、待っているゾンビの位置＝危険な場所もランごとに変わる。
中央の地面を基準にする案は、武器箱の候補が0件、最初の群れが2体しか出ず、やめた。

## 測定（ノーマル、手元の Chromium・swiftshader）
向きと離脱の時刻をランダムにした24回：
- 雲海へ落ちて救済された回数 0 / 24。
- 着地までの時間：滑空だけ 6.5〜8.8秒、途中で離脱 2.7〜5.6秒（飛行機の2.6秒は含まない）。
- 着地点：x −37〜45、z −18〜17 に散らばった。

飛行機から飛び降りる時刻もランダムにした8回（0〜2.4秒）：救済 0 / 8、飛び降りてから着地まで 4.6〜8.5秒（0秒＝町の約80 m外から飛び降りても8.5秒で町の上に着地）。

## 決めたこと（依頼主）
- 生存点も追跡も着地から（2026-11-28）。
- 落下ダメージなし。着地点は自由。ゾンビは空中にいる間から地上で待つ。
- 飛行機は短く、リトライでは飛ばす。スマホは左スティックで移動・ジャンプボタンで離脱。
- 飛行機からもパラグライダーからも、ジャンプボタン（表示「飛び降りる」）で飛び降りる。町の外で飛び降りたら町の上へ戻す（2026-11-28）。

## 飛行機の見た目（同日、「安物っぽい」の指摘で作り直し）
- 箱3つの仮の機体を、高翼・双発ターボプロップの輸送機に（モデルのファイルは足さず、円柱・球・箱の組み合わせ）：丸い胴体と機首、操縦席の窓と客室の窓、下面の色分け、スレート青の帯、後ろへ細くなる尾部、開いた後ろのランプ（プレイヤーはその端に立つ）、回る3枚羽根のプロペラ2基、T字の尾翼、翼端の赤・緑の灯火。色は石・スレートの灰色系（黄・橙は使わない）。
- 乗っている間はカメラを引く（距離9.5 m・高さ+1.3 m）。最初の向きは真後ろから約35°ずらし、機体を斜め後ろから見せる。飛び降りると約0.4秒で通常のカメラに戻る（`dash-boost.js` が毎フレーム決める距離に、その直後に重ねる）。
- 着地までは無敵を付けない（空中では被弾しないので、点滅で体が消えるのを避ける）。着地で従来どおり1.5秒。

## 行ける範囲（同日、「行ける範囲が限定されている」の指摘で修正）
- **原因**：真下に地面がない所を「壁」として最後に地面があった所へ押し戻していたので、町の中の隙間（屋根の溝・区画の間）も越えられなかった。中央から16方向にまっすぐ滑空すると、14方向で中央から13〜24 mの所に閉じ込められていた（町の端までは21〜69 m）。さらに、四角の範囲を足場の範囲から3 m内側にしていたので、端の足場の一部が範囲の外だった。
- **直し方**：
  - 行ける範囲を「どれかの足場から6 m以内」（町の形の範囲、2 mの格子）にした。その外（町のまわりの雲海）だけを柔らかい壁にする。範囲の中の隙間は、高い所なら自由に越えられる。
  - 屋根より低い所（高さ14 m未満）か、離脱して落ちている間に、真下に地面がない場合だけ、下がるのを止めて、今より低い一番近い足場の真上へ寄せる（隙間に落ちない）。
  - 地面とみなすのは高さ −6 m より上だけ（町の下の深い構造物を地面と数えない）。四角の範囲は足場の範囲より2 m外にして、最後の安全柵だけにした。
  - 一番遠い西の端（中央から69 m）にも余裕を持って届くよう、移動を毎秒12.5 mに。
- **測定**：中央から16方向にまっすぐ滑空して、全方向で町の端まで届く（5 m以内）・救済0回・着地まで最長8.8秒前後（`bench/paraglider-opening-browser.cjs` の「reach」）。
