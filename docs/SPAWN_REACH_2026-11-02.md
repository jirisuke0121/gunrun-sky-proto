# リスポーンから届くまでの遅さの対策（2026-11-02）

「ゾンビがリスポーン地点からこちらに来るまでが遅い・遠回りに見える」への対応。#116（近道を使う追跡）はプレイヤーの近くに手で置いた5地点だけを検証しており、実際のリスポーンは測っていなかったため、まず自然なリスポーンを測った。

## 測ったこと

`bench/spawn-arrival-browser.cjs`：止まっていて無敵のプレイヤーに、自然にリスポーンしたゾンビが届くまでの時間（旧市街・渓谷×乱数種4つ、開始位置も固定して再現可能）。待機が仕様の「配置」型は除く。

- 歩く距離の見積もり（ゾンビが追っているのと同じ経路の値）が届くまでの時間をよく予測する（相関0.72）。通常は25〜48で、遅い個体は66〜114に分かれていた。
- 遅かったのは、屋根など高所（高さ5.7〜11.7m）と、地面より低い窪み（高さ−3.5m）へのリスポーン。ゲーム開始時の最初の群れが中心で、20〜68秒かかっていた。開始画面を閉じる途中でリスポーンするため、これまでの判定の対象外だった。

## 変更

- `spawn-reach.js`：通常・落下・群れのリスポーンで、見積もりが60を超える地点、直線距離の1.6倍＋8mを超える地点、プレイヤーが地面より上にいるときの窪み（高さ−2m未満）を断る。待ち伏せ・配置・挟み撃ち・待ち伏せ型は、それぞれの距離の決め方があるため対象外。経路の値が未作成・地点がNAV外のときは何も変えない。
- `challenge-difficulty.js` の `spawnAllowed(point, kind)` から呼ぶ。通常の補充は既存の再試行、群れは16回の再選択で別の地点になる。リスポーンの数は変わらなかった（48→48体）。

## 結果（同じ乱数種・開始位置）

| | 変更前 | 変更後 |
| --- | --- | --- |
| 旧市街・平均 | 23.4秒 | 13.0秒 |
| 旧市街・90%点 | 41.6秒 | 20.6秒 |
| 旧市街・20秒超 | 24体中11体 | 23体中3体 |
| 渓谷 | 平均7.5秒・20秒超0 | 変化なし |

残る遅い個体は、回り込み（意図的な迂回）、降下型、西側の屋根からの1体。降下そのものに系統的な遅さは見つからなかった。

## 確認

- `node bench/spawn-reach.test.cjs`：判定の閾値、対象の種類、開始画面が閉じる途中の最初の群れ、窪み、経路の値が未作成・NAV外の安全側の動き。
- `bench/spawn-arrival-browser.cjs`（手動、約12分。`ARRIVAL_ASSERT=1` で平均12秒以下・90%点22秒以下・20秒超4体以下を確認。`SPAWN_GATE_OFF=1` で変更前と比較）。
- 乱数と開始位置を固定した上での比較であり、人間のプレイ・難易度体感・実機は未確認。標本は約48体で小さい。

## 追加：最初の群れは中央の高台から（同日）

ユーザー意図は「初回の出現は中央の高台から」。上の断る処理は高台発も止めてしまうため、開始直後の最初の群れに限り高台を復活させた。

- `opening-wave.js`：最初の群れのうち2体（最初の群れが4体以上のとき。3体以下では1体）を、中央の高台（高さ7〜9.5m・中心から20m以内・プレイヤーから20〜45m・互いに6m以上離す）に出す。降下型にして、西地区に元からある長い降下も使えるようにした。高台の候補がない・屋内・満員のときは通常の出現。残りと以後の補充は通常の選び方と断る処理。
- 降下型の経路計算が、実行できない降下（水平2.5m超など）を安く見積もっていた不一致を直した（`Pd` が `skyZombieRouting.edgeCost` に従う）。直す前は、高台の縁で降下を始められず約20秒（経路閉塞が付くまで）立ち止まっていた。
- リスポーン地点が歩行経路の外にある場合は断る。経路がなく、その場から動けなくなる個体が出ていたため。落下で出る個体の出発点（空中）は別扱いで判定しない。

結果（同じ乱数・開始位置）：旧市街の高台発は、立ち止まりが消えて16〜24秒、渓谷は6〜10秒。修正前の高台発は中央値35.6秒（17〜47秒、立ち止まりで40秒超も）だった。旧市街の高台発が約20秒かかるのは、使える降下が少なく階段などを回るため。さらに速くするには高台の縁に降下リンクを足す必要がある（未実施）。

`node bench/opening-wave.test.cjs`：高台の選び方、人数、練習・ミッション・満員・屋内での通常出現への切り替え。

## 追加：途中で止まる個体の自動解除（同日）

最初の群れの測定で、地上の同じ場所（旧市街の (-33,0,8) 付近）で、2つの経路ノードの間を行き来して30秒以上動けない個体が見つかった。通常の「進んでいない辺を20秒閉じる」判定は、辺が毎回変わると働かない。

- `zombie-pursuit.js`：プレイヤーに向かって歩いているだけの個体（気絶・閃光・分身・扉をこじ開け中・配置・登攀や降下の動作中・プレイヤーの3m以内を除く）が、3秒間に1.5m以上動かなければ、その間に試した辺をすべて20秒閉じて、経路を選び直す。
- 結果（旧市街・乱数種44の最初の群れ）：53秒→約20秒。

`node bench/zombie-stall.test.cjs`：行き来する停止は辺を閉じる、動いている・気絶・閃光・分身・動作中・近距離は閉じない。
