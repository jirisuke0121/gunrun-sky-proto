# 開始位置のランダム化（旧市街・高台）2026-11-05

## 何を変えたか
全難易度（入門・イージー・ノーマル・ハード）で、ラン開始位置を固定の街路（-42, 0, 8）から、測定済みの高台10か所のランダムに変えた（`start-spots.js`）。直前と同じ場所は選ばない。リトライ（もう一度）も引き直す。渓谷・練習場・オーナー再生・`?start=default` では従来の位置。自動操作ブラウザは固定位置のまま（既存テストを変えないため）で、テストからは `?random_start=1` / `?start_spot=<id>` で有効にする。

## 高台の条件（採用の基準）
1. 立つ高さが街路より4 m以上。ナビノード上で出口が4つ以上、屋外、1.5秒後も位置が動かない。
2. 立ち止まった無敵のプレイヤーに、最初の追手が触れるまでの時間（`first`）：
   - ノーマル・ハード：全ての試行が4.5〜12秒、中央値5秒以上（街路の既定位置はノーマル7.0〜8.0秒、ハード6.5〜7.3秒）。
   - 入門：全ての試行が5〜16秒（街路の既定位置は11〜12秒）。
3. 追手が実際に届くこと（届かない場所は「安全な島」であって開始位置にしない）。

## 見つかったこと（今回は直していない）
- 既存の鉄棒スポット「⑥ 北バルコニー」の入口 (2, 4, -15.5) では、ノーマル3シードとも60秒立っていても追手が1体も届かなかった（5 m離れた (-3, 4, -16) は3〜4秒で届く）。ゾンビの出現側の到達制限（`spawn-reach.js`）が、その足場を「届かない場所」として扱い、追手が来なくなっている可能性がある。ランダム開始の候補には入れていない。
- 入門は追手が少ないため、同じ位置でも到達が遅くなる位置がある（(-29,4.4,-30) は25秒以内に誰も届かなかった）。

## 再現
`node bench/start-spots.test.cjs`（条件・間隔・抽選・切替）／`node bench/start-spots-browser.cjs`（全難易度で一覧の位置に立つこと、位置が変わること、リトライで引き直すこと、渓谷・`?start=default`・自動操作は従来の位置）。到達時間の測定は、ナビノード抽出＋`__game.startGame(位置)` で立ち止まり無敵のプレイヤーに最初の追手が触れるまで（`bench/spawn-arrival-browser.cjs` と同じ考え方）。

## ランキングの版
`ranked-rules.js` の版（`corridor-balanced-score-v14`）は変えていない。版は固定する物理・戦闘設定の契約で、開始位置は含まれない。上げると Worker の許可リスト（`server/worker.js`）の更新と、既存の順位の扱いが必要になる。開始位置で得点の出やすさが変わりうるが、上記の基準（最初の追手までの時間を街路の位置の近くに揃える）で差を抑えている。版を上げて順位を分けるかは別途判断。
