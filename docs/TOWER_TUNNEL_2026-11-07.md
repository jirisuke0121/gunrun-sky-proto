# 塔のトンネル（2026-11-07）

長い斜面を滑り降りる → 塔の中をU字に抜ける → 屋上の穴から打ち上がり、マップ全体を見渡す。旧市街（`index.html`）のみ。

## 経路と数値（座標は x 東・y 上・z 南）

| 区間 | 内容 |
|---|---|
| 入口 | 既存の長い斜面（x14〜40）の終端（x14, y8）。塔の屋上の縁から幅2.5 m（z −10.0〜−7.5）の坑に続く |
| 滑り台 | 勾配 0.383、x14 → x2.07、y8 → 3.43、長さ約12.8 m。段差0.2 mの隠し箱（`hd`）で、既存の斜面と同じ滑り方（`slideSlope`） |
| 底 | x2.07, y3.43。ここに5.5 m/s以上で着くと射出が始まる（走って降りてもよい。止まっていれば何も起きない） |
| U字 | 半径5.1 m、84°。底から出口の縁（x −3.0, y8.0）まで約7.5 m。速度は着いた速さ（9〜15 m/s）から24.6 m/s へ上がる |
| 出口 | 屋上の穴 x −3.0〜−1.4、z −10.0〜−7.5。穴の東端は、立った体（半径0.32・高さ1.75）が出口で屋根の縁に触れない位置 |
| 飛行 | 初速 (−2.57, 24.5, +1.0) m/s、重力20。頂点 y22.96、20 m以上に約1.1秒、飛行2.45秒 |
| 着地 | 屋上の x −9.3, y8, z −7.2〜−5.5（入った位置による）。西の小屋（x −12〜−9, z −12〜−8.5）の上には降りない |

## 屋内通路に支障を出さない掘り方

- 掘るのは帯 z −10.0〜−7.5 だけ。帯の外の箱は1つも変えない（体積が同じことをテストで確認）。
- 東の上段回廊（x11〜13、床 y4、天井 y7.6）の真上は、厚さ0.3 mの殻（滑り台の裏側）にする。殻の下端は y6.65 以上で、床から天井まで **2.6 m以上** 残る（立った体は1.75 m）。回廊の下段（y0〜3.6）は変わらない。
- 回廊の梁（z −7.5〜−6.5）は帯の外。触らない。階段・扉・北回廊（z −13〜−11）・西／南の回廊も触らない。
- 芯（x −11〜11 の塊）は帯の中の y3.2 より上だけ取り除き、滑り台とU字の下は柱で詰め直す。東の外壁（x13〜14）も、殻の下を詰めて壁として残す。
- 屋根は入口の坑（x7.2〜14）と出口の穴（x −3.0〜−1.4）の2か所だけ開ける。間（x −1.4〜7.2）は屋根が残り、トンネルになる。
- 東の回廊側から見ると、帯の部分だけ天井が斜めの殻になる。

## 射出を「突然の加速」にしない（AGENTS §3）

U字の面に橙の帯、出口の穴に橙の縁と脈打つ光の柱を置き、「ここを通ると打ち上がる」と見て分かるようにした。ジャンプ台と同じく、決まった場所を通ったときだけ決まった速度が与えられる。技を決めたことによる加速や、被弾時の押し出しではない。ゾンビと、速度が足りない人は、このトンネルを通常の地形として歩く。

## 検証

- `node bench/tower-tunnel.test.cjs` … 回廊の天井高、帯の外の体積、屋根の開口、滑り台の段差・頭上、U字の出口の余裕、頂点・着地の数値。
- `node bench/tower-tunnel-browser.cjs` … 実物理で、滑り降り → 打ち上げ（頂点22.96 m、20 m以上に1.08秒）→ 屋上着地、走って降りても発動、止まっていれば発動しない、東の回廊を歩いて通れる、試合をまたいで持ち越さない。
- 既存の関連テスト（北壁・写真ルート・屋内アクセス・屋根・壁走り・ゾンビ経路・ミニマップ・ジャンプ台など）は変更後も通過。
