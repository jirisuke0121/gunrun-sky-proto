# 塔のトンネル（2026-11-07）

長い斜面を滑り降りる → 塔の中をU字に抜ける → 屋上の穴から西へ流れながら打ち上がり、マップ全体を見渡して西の広場に降りる。旧市街（`index.html`）のみ。

## 経路と数値（座標は x 東・y 上・z 南）

| 区間 | 内容 |
|---|---|
| 入口 | 既存の長い斜面（x14〜40）の終端（x14, y8）。塔の屋上の縁から幅2.5 m（z −10.0〜−7.5）の坑に続く |
| 滑り台 | 勾配 0.383、x14 → x2.07、y8 → 3.43、長さ約12.8 m。段差0.2 mの隠し箱（`hd`）で、既存の斜面と同じ滑り方（`slideSlope`） |
| 入場券 | 入口の線（x=14）を、斜面から西向きに、滑りながら12.5 m/s以上で通った瞬間だけ出る（下の「入口の制限」） |
| 底 | x2.07, y3.43。入場券があり、11 m/s以上が残っていると射出が始まる。止まっていれば何も起きない |

## 屋内通路に支障を出さない掘り方

- 掘るのは帯 z −10.0〜−7.5 だけ。帯の外の箱は1つも変えない（体積が同じことをテストで確認）。
- 東の上段回廊（x11〜13、床 y4、天井 y7.6）の真上は、厚さ0.3 mの殻（滑り台の裏側）にする。殻の下端は y6.65 以上で、床から天井まで **2.6 m以上** 残る（立った体は1.75 m）。回廊の下段（y0〜3.6）は変わらない。
- 回廊の梁（z −7.5〜−6.5）は帯の外。触らない。階段・扉・北回廊（z −13〜−11）・西／南の回廊も触らない。
- 芯（x −11〜11 の塊）は帯の中の y3.2 より上だけ取り除き、滑り台とU字の下は柱で詰め直す。東の外壁（x13〜14）も、殻の下を詰めて壁として残す。
- 屋根は入口の坑（x7.2〜14）と出口の穴（x −3.0〜−1.4）の2か所だけ開ける。間（x −1.4〜7.2）は屋根が残り、トンネルになる。
- 東の回廊側から見ると、帯の部分だけ天井が斜めの殻になる。

## 入口の制限（誰でも即発動する乱用を防ぐ）

- 入口の線（x=14、帯の中、屋上の高さ）を、西向きに、スライディング中に、12.5 m/s以上で通った人にだけ「入場券」を与える。
- 実測（スライディング開始位置と入口での速さ）: x16→5.8、x20→8.2、x24→10.0、x28→11.3、x30→12.1、x34→13.2、x38→14.5 m/s。つまり斜面の上から約4割（x31より上）で滑り始め、約2秒以上滑らないと券は出ない。
- 券は、底まで残り、底でも11 m/s以上であれば打ち上げに使われる。入口から東へ戻る・帯を外れる・6秒たつ・試合が終わる、のどれかで失効する。
- 次のものは券が出ない: 屋上から走って入る、屋上の縁から滑る、斜面の中ほど（x28）から滑る、坑の途中へ落ちてから滑る。坑や穴には落ちるが、斜面を歩いて登って出られる。
- 打ち上げの後にもう一度使うには、長い斜面を登り直す必要がある。これが自然な間隔になるので、クールダウンは付けていない。

## 射出を「突然の加速」にしない（AGENTS §3）

U字の面に橙の帯、出口の穴に橙の縁と脈打つ光の柱を置き、「ここを通ると打ち上がる」と見て分かるようにした。ジャンプ台と同じく、決まった場所を通ったときだけ決まった速度が与えられる。技を決めたことによる加速や、被弾時の押し出しではない。ゾンビと、入場券のない人は、このトンネルを通常の地形として歩く。
