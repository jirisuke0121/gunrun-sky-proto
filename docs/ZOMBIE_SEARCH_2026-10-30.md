# 見失った後の捜索

旧市街・岩壁渓谷の本番で、追跡を振り切った成果が残るようにする。

- ゾンビは視認した位置を記憶する。遮蔽物に隠れると、その位置へ向かう。到達、または通常は最大2.5秒で周辺捜索へ移る。最後に確認した接地地点が1.25m以上高い場合は最大8秒待ち、4秒停滞後の登攀を開始できるようにする。開始した登攀はその記憶地点へ登り切り、再視認できなければ周辺捜索へ移る。
- 捜索は既定10秒。記憶した場所の周辺にある到達可能なノードをランダムに選び、最大1.35m/sで歩く。遠くて到達できなかった場合は、自分の周辺を探す。
- 捜索終了後はその周辺で通常徘徊する。時間切れでプレイヤーの現在位置を取得しない。
- 再発見には、遮蔽物のない視線と約0.45秒以上の継続した認識が必要。捜索中の視野は160度。認識途中の短い視認は体の向きが変わっても保持し、胸と頭のどちらかが見えていれば認識を続ける。しゃがみ時は実際の体高に合わせる。2.2m以内でも遮蔽物越しには気づかず、攻撃できない。閃光弾の効果中は視認しない。
- 移動中の足音は既存の `hearR`（既定8m）で注意を向ける。遮蔽越しの音は1秒に1回まで、その瞬間の位置への調査とし、遮蔽を無視した視認や攻撃にはしない。静止中は足音で位置を更新しない。
- 銃声は発砲した瞬間の位置への調査になる。隠れた相手を連続追尾する権限にはならず、逃走後の増援停止も解除しない。
- 全ての追手が見失って捜索に移ったら、「追跡を振り切った」と短い音を出す。上部に捜索中の表示を出す。まだ追う個体がいる間は成功扱いにしない。
- 成功後の10秒は補充・前方出現・挟み撃ち・追加の追跡者を停止。予約済みの挟み撃ちも取り消す。まだ姿を見せていない出現演出は待機する。既に存在する敵との自然な遭遇は起こり得る。
- 通常・飛び降り型・追跡者・柱登りに共通適用。柱登りは視認中の相手か記憶した地点だけを目標にし、対象の記憶終了・被弾・閃光・足場無効化で中断する。見失った後は現在位置用の経路フィールドも参照しない。技を教える既存ミッションは従来の進行を保つ。
- 分身への誘導中は分身の移動・経路を優先する。本体の視認記憶は独立して保持し、分身が消えても隠れた本体の現在位置には復帰しない。
- 調整項目は「見失った後の捜索時間」。従来の既定4秒は10秒へ移行し、4秒以外に調整していた値は維持する。
- 過去の `enhancements.js` にあった常時無効化を除去し、初回は見失いを有効にする。以後の個別調整は保存する。視線は個体ごとに0.2秒間隔で確認し、毎フレームの全経路再計算を行わない。

共通実装は `zombie-search.js`。本体の更新・移動・射撃・増援処理に小さな呼び出しを置く。記憶・捜索中の経路はプレイヤー用の現在位置フィールドを使わず、目撃・音・ローカル徘徊の目的地から作る。フィールドのキャッシュは12件まで。

確認用:

- `node bench/zombie-search.test.cjs`：両HTMLの実際のZombie.update/pickEdgeを使う。目撃地点の固定、10秒捜索、時間切れ、近距離の遮蔽、音の位置固定、閃光、特殊個体、全追手の条件、リセット。
- `node bench/zombie-search-browser.cjs`：GitHubの既存ブラウザ検証環境で両マップ×PC/タッチを描画。実地形の遮蔽物を使った追跡解除、増援停止、残り時間、停止/再開、徘徊の移動、再発見を確認し、スクリーンショットとJSONを保存する。

iPhone実機での操作感はこの自動検証には含めない。
