# 足場グラフの脱出解析（旧市街）

`node tools/escape-graph.cjs [--difficulty=easy|normal|hard]` で `index.html`（上から見た地図）と `summary.json` を作り直す。ゲーム本体は変更しない。

## 何を調べているか
- ゾンビ用の足場の点と線（NAV、4087点・37668線）に、人間だけが使えるジップと鉄棒ルートを足した図を使う。
- 各足場に「7m離れた四方からゾンビが迫った」状況を置く。次の条件を満たす脱出先（水平6m以上先）があれば脱出可、なければ詰み。
  - 6秒以内に着く。
  - 脱出先で、追手より1秒以上先に着く。
  - 経路の**途中の足場すべて**で、追手より0.5秒以上先に着く（途中でゾンビに近づく経路は除く）。
- 人間の移動時間は `challenge-difficulty.js` の travelCost、ゾンビは pursuitCost と `zombie-routing.js` の跳び移り規則に合わせた。

## 結果（旧市街・対象は四方に追手を置ける足場 2287点）
| 難易度 | 詰み | ジップ・鉄棒がないと詰む | 通常の移動で脱出可 |
| --- | ---: | ---: | ---: |
| easy | 1795 | 37 | 455 |
| normal | 2050 | 31 | 206 |
| hard | 2169 | 12 | 106 |

「途中も安全」の条件を入れる前は、normalの詰みが1056点でした。到着時点の余裕しか見ておらず、実ゲームで試すと5件中3件が追いつかれたため、条件を足して作り直しました。この数字は、旧市街では**四方を囲まれたらほぼ詰む**ことを示します。

## 限界（推定であり、実ゲームの再現ではない）
- フック（12か所）は未反映。着地点の決め方がまだ不明なため。壁走りも未反映。
- ジップの速さ（12m/s）と鉄棒ルートの所要時間（2.5秒）は概算。
- ゾンビの置き方は「各象限の7m付近1体」の固定。実際の群れの動きは反映していない。
- 経路上の動きを実ゲームの物理で通せるかは未検証。

## 自由フック（1ランに2回）の効果（`tools/hook-coverage.cjs`、normal）
「詰み」2045点（四方を囲まれて、通常の移動では逃げられない足場）のうち、好きな足場にフックして上に乗ると助かる点の数。助かる＝追手が着くまでの時間 − 自分が乗るまでの時間 が、しきい値以上。

| 条件 | 稼ぐ時間 | 1回 | 2回 | ゾンビが届かない足場を除く（1回／2回） |
| --- | --- | ---: | ---: | ---: |
| 提案どおり（水平12m以内・+3〜+8m） | 4秒以上 | 373（18%） | 417（20%） | 191（9%）／234（11%） |
| 提案どおり | 8秒以上 | 227（11%） | 247（12%） | 24（1%）／24（1%） |
| 本編のフック射程（3D 22m以内・+2m以上） | 4秒以上 | 700（34%） | 776（38%） | 159（8%）／161（8%） |
| 本編のフック射程 | 8秒以上 | 576（28%） | 695（34%） | 34（2%）／38（2%） |

- 「ゾンビが届かない足場」は、NAV上でゾンビの経路がない足場。実ゲームではゾンビはどこでも登れる方針なので、実際の効果は「除く」側に近いと考えられる。
- 前提: 動き出し0.4秒、引く速さ18m/s（本編の hookSpeed）、乗り上げ0.5秒。フックの先は壁にさえぎられないこと（実ゲームの raycast で確認）。
- 未確認: 実ゲームでのゾンビの登攀時間（NAVの見積もりと異なる可能性）、フックの再使用待ち（本編は5秒）。

## 救済スキル（ボタン1つ・自動）の実ゲーム検証（`tools/free-hook-verify.cjs`、normal）
詰み75点から、4体に囲まれた状態でボタンを押した結果。

| 結果 | 点数 |
| --- | ---: |
| 高台に乗れた | 41 |
| 足場は選べたが乗れなかった | 4 |
| 射程内に足場がない | 11 |
| 引く動きが壁や天井で止まる足場しかない | 13 |
| 足場がゾンビの近くしかない | 6 |

乗れた41点で、乗ってから追手が追いつくまで中央値4.4秒（1.4〜11.9秒）。8点は14秒以内に追いつかれなかった。
