# 足場グラフの脱出解析（旧市街）

`node tools/escape-graph.cjs [--difficulty=easy|normal|hard]` で `index.html`（上から見た地図）と `summary.json` を作り直す。ゲーム本体は変更しない。

## 何を調べているか
- ゾンビ用の足場の点と線（NAV、4087点・37668線）に、人間だけが使えるジップと鉄棒ルートを足した図を使う。
- 各足場に「7m離れた四方からゾンビが迫った」状況を置く。6秒以内に、追手より1秒以上先に着ける足場（水平6m以上先）があれば脱出可、なければ詰み。
- 人間の移動時間は `challenge-difficulty.js` の travelCost、ゾンビは pursuitCost と `zombie-routing.js` の跳び移り規則に合わせた。

## 結果（旧市街・対象は四方に追手を置ける足場 2287点）
| 難易度 | 詰み | ジップ・鉄棒がないと詰む | 通常の移動で脱出可 |
| --- | ---: | ---: | ---: |
| easy | 531 | 312 | 1444 |
| normal | 1056 | 423 | 808 |
| hard | 1592 | 332 | 363 |

## 限界（推定であり、実ゲームの再現ではない）
- フック（12か所）は未反映。着地点の決め方がまだ不明なため。壁走りも未反映。
- ジップの速さ（12m/s）と鉄棒ルートの所要時間（2.5秒）は概算。
- ゾンビの置き方は「各象限の7m付近1体」の固定。実際の群れの動きは反映していない。
- 経路上の動きを実ゲームの物理で通せるかは未検証。
