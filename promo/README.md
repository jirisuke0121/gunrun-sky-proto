## covers/（2026-11-23 撮り直し。11/21 版は街の見た目を直す前の色だった）
**2026-11-27：ホームの絵だけ、今のゾンビ（服・髪を描いた Unity の体と、町の人3種）で撮り直した。表紙3枚は 11/23 のまま（服を描く前の体）。次に表紙を使う前に撮り直す。**

CrazyGames の必須サイズ（横 1920x1080・縦 800x1200・正方形 800x800）。文字はタイトルだけ（CrazyGames は「Play」「New」などの文字を禁止）。
ホームの絵・初回カード（`assets/lobby/old-town-chase.webp`）と同じ場面：旧市街の東、高さ14.4mの屋上の縁から、人間が雲海の上へ跳ぶ。ゾンビ4体が縁で手を伸ばし、奥に城の岩山。

作り直し方（ゲーム内のカメラで撮る。ローカルで `python3 -m http.server 8899` を立てておく）:
1. `stage-shot.cjs` で撮影。使った設定：
   `WARM=60 HIDEPOLES=1 W=3200 H=1800 SLOTS='[[0.9,0.0,0.2,1.0],[1.8,-0.7,-0.15,1.05],[2.5,0.4,0.3,0.97],[1.2,-1.4,0.0,1.0]]' SPECS='[{"id":"hero","x":46,"z":-10,"h":14.4,"a":2.749,"apex":8,"runner":[2.0,1.3,1.0]}]' CAMS='[{"n":"E6","f":-3.0,"s":3.4,"u":1.8,"tf":2.2,"ts":-1.2,"tu":1.0,"fov":58}]'`
   - 11/27 のホームの絵は、上の設定に `WANT=zombie-decayed-man.glb,zombie-old-worker.glb,zombie-gunrun-standard.glb,zombie-hoodie.glb` を足した（追う4体のモデルを SLOTS の順に指定。手前は Unity の体）。服の色や腕の姿勢は撮るたびに変わるので、同じ絵にはならない。ゾンビが1体も写らないことがある（11/27 は `main` で3回中1回。原因は未調査）ので、撮った絵は必ず目で確認する。
   - SLOTS は1体ずつ [縁から後ろへm, 横へm, 向きのずれ(rad), 大きさ]。向き・大きさ・歩きの位相もずらして、体ごとの違いを出す。
   - `runner` は人間を置く位置 [縁から先へm, 上へm, 横へm]（跳びのアニメーションはそのまま）。
   - 写さない物：フックの印・ロープ台・ドカン・光の柱・細い柱・拾える物・カメラに付いた白い帯。
   - 候補の縁は `gap-scan`（高い屋上の縁の一覧）から選んだ。x=21,z=-6 と x=46,z=-10 が雲海と城を背にできる。
2. `grade.py <撮影したpng> <出力名>` でホーム用（1920x1080 webp）。
3. `make_covers.py <撮影したpng>` で3枚の表紙（字体は Inter Display Black Italic、OFL）。

ゲームに無いもの（庇・バルコニー・ぶら下がるロープなど）は描き足さない。実際の画面と違う絵はポータルで信用を落とす。
