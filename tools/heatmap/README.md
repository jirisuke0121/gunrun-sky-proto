# 被弾・死亡ヒートマップ

プレイ記録（D1の `runs.json.mistakes`）に入っている「ライフを1つ失った出来事」の位置を、マップを上から見た図に重ねて表示します。**ゲーム本体・Worker・DBの変更はありません**（既存の記録をそのまま読みます）。

| 種類 | 元データ | 意味 |
|---|---|---|
| 被弾（橙） | `mistakes[k=hit]` | ゾンビに噛まれてライフを失った位置 |
| 落下（青） | `mistakes[k=fall]` | 落下でライフを失った位置（落ちはじめた足場の高さ） |
| 死亡（赤） | 最後のライフを失った出来事（`life=0` かつ `reason` が `caught`/`fell`） | 被弾か落下かは詳細に表示 |

## 見る方法

1. **GitHub Pages上で開く**：`https://jirisuke0121.github.io/gunrun-sky-proto/tools/heatmap/heatmap.html` → ADMIN_TOKEN を入れて「サーバーから読み込む」（最新N件、既定200件。1プレイ約100KBあるので件数を増やすと重くなる）。合言葉はそのタブの間だけ保存。
2. **JSONを開く**：`/runs?full=1` の応答、または記録の配列を保存したファイル。
3. **データ入りの単独HTML**：`node tools/heatmap/build-standalone.cjs 記録.json 出力.html`（記録は公開リポジトリに入れない）。

操作：マップ・難易度・種類・高さ・時間帯で絞り込み、「多い場所 TOP6」をクリックで地図上に印、点をクリックで詳細（時間・場所名・最寄りのゾンビ・9m以内の数）。

## マップ形状の更新

マップを変えたら `node tools/heatmap/export-map.cjs`（playwright が必要）で `heatmap-maps.json`（当たり判定の箱）を作り直す。

## 注意

- 記録の `build` が `-dev` で終わるものと、入門モード(`intro`)は除外。
- `mistakes` は1プレイにつきライフを失った回数分だけ入る。ライフを失わない接触は入らない。
- 件数が少ないうちは1人のプレイが大きく効く。「何プレイ」の数も一緒に見ること。
