# マップの測定道具

ゲーム本体（index.html）を画面なしのブラウザで開き、ゲームの経路データ（`window.__game.NAV`）を使って測ります。

準備：リポジトリの直下で `python3 -m http.server 8765` を起動し、`npm i playwright` 済みであること。

| 道具 | 何を測るか | 実行 |
|---|---|---|
| `runsim.mjs` + `sim.js` + `extra.js` | 追いかけっこボット。上手い人・雑な人・地面だけの人が何秒逃げられるか（ゾンビは0.75倍速、40回×2組で判定） | `node runsim.mjs index.html 40 1000 tag 0.75` |
| `runexits.mjs` + `exits.js` | 高い場所の出口の数（行き止まり）と、細い所から次の出口までの距離 | `node runexits.mjs index.html tag` |
| `trick.mjs` | 最速ルートの技の間隔、ゾンビが来られない場所、逃げ技まで1.5秒以内の割合 | `node trick.mjs index.html` |

ボットのルール：ゲームと同じ視線のルール（8m以内は気づく、40m以内で視線が通れば見つかる、0.6秒隠れると見失い、4秒で気配が戻る）、ゾンビの圧力（最大18体、半分が回り込み、4割が前方に出る、40秒ごとの大量発生、20秒後の追跡者、12秒静かだと待ち伏せ）。銃・ナイフの押し返しとライフ3つは入れていないので、実際より厳しい。
